# ⌘P 快速打开

> 状态：**2026-10-31 定方案并落地（Mac）**，待用户实测（§5）。

用户原话：「加一个 cmd p 打开快捷入口就像 spotlight 那样」。

两条拍板（用户 2026-10-31 选的）：

1. **搜什么**：当前窗口工作区里的 **PDF + Markdown 笔记 + 画板 + 习题的各组**（全部 / 错题本 / 收藏 / 每本书 / 每一章）。
   没选的：菜单命令、别的工作区。
2. **在哪出现**：**当前窗口上方居中**（像 Xcode 的 Open Quickly，多窗口、多屏幕时跟着当前窗口走）；外观照聚焦搜索。
   没选的：屏幕上方居中。

## 1. 交互

- **⌘P**（文件 ›「快速打开…」；设置 › 快捷键 ›「视图」里可改）：弹出；再按一次、Esc、点到别处（面板失去 key）都收起。
  App 没有「打印」，⌘P 不和谁冲突。
- 输入即过滤；↑↓（⌃P / ⌃N）选，**回车打开**，鼠标单击一行直接打开。打开 = 侧栏单击那一行
  （`TabsModel.open` / `openMarkdown` / `openBoard` / `openExercises`，习题照旧在公用标签里换）。
- 没输入时按「上次打开」列（PDF、笔记、画板混排，没打开过的在后面），习题各组跟在后面、按侧栏的先后。
- 匹配同 Agent 输入框 `@`（`AgentMentionMatch.rank`，泛型那一版）：名字开头 > 名字里含 > 第二行里含 > 按顺序模糊；
  不分大小写 / 变音符号 / 全半角。第二行写着类别（「PDF」「Markdown 笔记」「画板笔记」「习题」），所以输入「习题」能筛出各组题。
  最多列 60 条，一屏 8 行、多了滚。

## 2. 外观（红线③④）

- 无边框 `NSPanel`（能成为 key，要打字），**阅读窗的子窗口**（跟着窗口移动）；内容是系统玻璃 `NSGlassEffectView`（圆角 22）。
- 顶上一行：放大镜（SF Symbols）+ 无边框输入框（20pt）；下面一条系统分隔线 + `.inset` 表格（行高 44：图标 + 名字 14pt + 第二行 11pt）。
- 玻璃上的字一律 `labelColor`，层级只靠字号；选中行用系统选中样式，表格不当第一响应者也按活动样式画（同 `AgentMentionPopup`）。
- 宽 640（窗口太窄时收到窗口宽减 48，最窄 360）；顶边在窗口顶往下约六分之一（至少 80pt，让开工具栏）；高度随结果变、顶边不动。
- 输入了但没结果：结果区一行「没有找到」。
