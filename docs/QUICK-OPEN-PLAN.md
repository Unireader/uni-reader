# ⌘P 快速打开

> 状态：**2026-10-31 定方案并落地（Mac）**，待用户实测（§5）。2026-11-28 加模糊搜索 + 单道题 + 目录项（§6），待实测（§6.5）。

用户原话：「加一个 cmd p 打开快捷入口就像 spotlight 那样」。

两条拍板（用户 2026-10-31 选的）：

1. **搜什么**：当前窗口工作区里的 **PDF + Markdown 笔记 + 画板 + 习题的各组**（全部 / 错题本 / 收藏 / 每本书 / 每一章）。
   没选的：菜单命令、别的工作区。
2. **在哪出现**：**当前窗口上方居中**（像 Xcode 的 Open Quickly，多窗口、多屏幕时跟着当前窗口走）；外观照聚焦搜索。
   没选的：屏幕上方居中。

## 1. 交互

- **⌘P**（文件 ›「快速打开…」；设置 › 快捷键 ›「视图」里可改）：弹出；再按一次、Esc、点到别处（面板失去 key）都收起。
  App 没有「打印」，⌘P 不和谁冲突。
- 输入即过滤；↑↓（⌃P / ⌃N）选，**回车打开**，鼠标单击一行直接打开。打开 = 侧栏单击那一行
  （`TabsModel.open` / `openMarkdown` / `openBoard` / `openExercises`，习题照旧在公用标签里换）。
- 没输入时按「上次打开」列（PDF、笔记、画板混排，没打开过的在后面），习题各组跟在后面、按侧栏的先后。
- 匹配同 Agent 输入框 `@`（`AgentMentionMatch.rank`，泛型那一版）：名字开头 > 名字里含 > 第二行里含 > 按顺序模糊；
  不分大小写 / 变音符号 / 全半角。第二行写着类别（「PDF」「Markdown 笔记」「画板笔记」「习题」），所以输入「习题」能筛出各组题。
  最多列 60 条，一屏 8 行、多了滚。

## 2. 外观（红线③④）

- 无边框 `NSPanel`（能成为 key，要打字），**阅读窗的子窗口**（跟着窗口移动）；内容是系统玻璃 `NSGlassEffectView`（圆角 22）。
- 顶上一行：放大镜（SF Symbols）+ 无边框输入框（20pt）；下面一条系统分隔线 + `.inset` 表格（行高 44：图标 + 名字 14pt + 第二行 11pt）。
- 玻璃上的字一律 `labelColor`，层级只靠字号；选中行用系统选中样式，表格不当第一响应者也按活动样式画（同 `AgentMentionPopup`）。
- 宽 640（窗口太窄时收到窗口宽减 48，最窄 360）；顶边在窗口顶往下约六分之一（至少 80pt，让开工具栏）；高度随结果变、顶边不动。
- 输入了但没结果：结果区一行「没有找到」。

## 6. 模糊搜索 + 单道题 + 目录项（2026-11-28）

用户原话：「优化下 cmd+p 的搜索，支持一些模糊搜索，以及练习题的搜索比如我希望搜索 1000题 基础2.7，或者 例2.7；能搜索 toc，具体内容的匹配」。

### 6.1 匹配（`App/QuickOpenMatch.swift`，只依赖 Foundation；⌘P 不再用 `AgentMentionMatch.rank`，`@` 那边不变）
- 输入按空白拆段，**每段都要中**、顺序不限。一段先整段找；不中再在「字 ↔ 数字」交界处拆块、每块都要中（「基础2.7」→「基础」「2.7」）。
- 以数字开头 / 结尾的块认数字边界：「2.7」不中「12.7」「2.71」「1.2.7」，「100」不中「1000」。
- 分档：名字开头 100 > 名字含 80~60 > 拼音（首字母开头 70 / 全拼开头 65 / 含 60、55）> 第二行含 50 > 长内容含 40 > 模糊（名字里按顺序出现各字）30 起递减。
  各段的分相加，同分保持原顺序。含数字的段、单道题不做模糊。
- 拼音只算书 / 笔记 / 画板 / 习题组的名字（`applyingTransform(.mandarinToLatin)` 逐字算、按字缓存；多音字取系统给的那个读音）。

### 6.2 新增两类条目（只在输入后出现，没输入时照旧只列原来那些）
- **单道题**：名字 = 小节 + 题号 + 题干开头；第二行 = 习题 · 书名 · 章节 · 第几页；长内容 = 题干全文（前 400 字）、章节、标签、文章标题，
  以及别名：题号是纯数字时接在最深一级带序号的章节后面（「第2章」的第 7 题也能用「2.7」搜到；认「第二章」「第12章」「2.3 xx」「Chapter 4」）。
  打开 = 在它那本书的题里停到这一道（`AppDelegate.showExercises(.document(书), at:)`；不关联 PDF 的题 = 它那个分组），在当前窗口。
- **目录项**：每篇取当前生效的目录（`Window/QuickOpen/QuickOpenTOCCache.swift`）——开着的用会话里的 `toc`；没开有自建目录用自建目录；
  否则 PDF 自带目录，**后台**解析、按「路径 + 修改时间」缓存到 App 退出，解析好了面板重排（保住当前选中的那条）。
  名字 = 目录项；第二行 = 目录 · 书名 › 上级 · 第几页。打开 = 当前窗口开这篇（开着就切过去）并跳到那里（记一条目录跳转历史）。
- 题干全文 / 目录不搜 PDF 正文（那是 MCP `search` 的事）。
