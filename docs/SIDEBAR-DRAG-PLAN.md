## 1. 哪些能拖、放到哪

| 一组 | 能拖的 | 不能拖的 | 顺序存在哪 |
|---|---|---|---|
| 书库的一个分组（或不分组时整个书库） | 书 | — | `document.sort_order`（`reorderDocuments`，右键上移 / 下移写的也是它；一个分组 = 整份书库顺序里的几个位置） |
| 笔记源 / 笔记目录 | 这一层的笔记 | 子目录（照旧按名字、在笔记前面） | `meta.note_order` |
| 画板 | 画板 | — | `meta.board_order` |
| 习题（顶层） | 全部 / 错题本 / 收藏 / 每本书，彼此随意换（用户拖了「收藏」才知道要这样，§6） | — | `meta.exercise_order`（`ExerciseScope.key` 数组） |
| 错题本 / 收藏底下 | 书 | 章节（跟着书里的页码走） | 同上：这几本书是顶层顺序里的几个位置，按新顺序填回去 |

- 多选的几行一起拖 = 整批挪，保持彼此原来的先后；几行不在同一组 → 不接。
- 放的位置：两行之间；悬在同组的某一行上 → 按指针在它的上半 / 下半换成放到它前面 / 后面；
  超出能拖的那一段（比如拖到笔记目录的子目录之间、习题的「全部」之上）→ 收到这一段的头 / 尾。
- **排法一律**：拖过的按拖的先后；**没拖过的（新加的）排在最前**、彼此保持原来的规则（书库按上次打开、笔记按名字、
  画板按最近打开、练习库按书库顺序）——同书库「没排过的书在最前」的老规矩，新东西出现在看得见的地方。
- **拖起来不打开**：原来鼠标一按下选中就打开那一行；现在鼠标按下时只选中，松手（单击）才打开，拖起来排序那一下不会把书打开、
  不会换掉公用习题标签。键盘上下移动照旧当场打开。

## 2. 存储

- 书库沿用列；另外三种库里没有现成的列（笔记的 `md_doc.sort_order` 只覆盖内建 `Notes/`，引用的外部目录没有行；画板表没有顺序列），
  各存一个 `meta` 键（JSON）。**不升表结构，安卓不用跟**。
  - `board_order`：board id 数组。
  - `exercise_order`：习题那一段顶层各行的 `ExerciseScope.key` 数组（`all` / `wrong` / `starred` / `doc:<id>`）。
    第一版开发包存过只有 document id 的，读的时候当成 `doc:<id>`。
  - `note_order`：`{ 源 id: { 目录相对路径（根 = ""）: [笔记的源内相对路径…] } }`。笔记改名 / 挪目录后它在旧顺序里就找不到了，
    回到「没排过」（在最前），不影响别的。
- 三个键进了同步白名单 `MirrorFp.syncedMetaKeys`：离线镜像、服务器都带着走；两端都改了按 meta 的老规矩保留源那份。
  🔴 服务器认同一张白名单（`Sources/Store/` 是符号链接）：**旧版服务器会把这三个键丢掉**（推送整理那一步记成 unchanged），
  换了新服务器才跨设备同步。安卓的白名单没有它们（平板上不拖，安卓的画板列表照旧按它自己的规则排）。
- 平板抽屉的习题分组（`exGroups`）、⌘P 里的习题各组用同一份（`WorkspaceManager.exerciseGroups()`）；平板的画板列表跟着 `boards`。

## 6. 第一版的问题（2026-10-31 用户实测）

- 用户截图：拖习题的「收藏」（之后说「全部」「错题本」都一样）→ 放下后那一行变成一行空白，选中的那本书倒是挪到了最前。
- 成因（按现象推断，没有在真 App 里打点证实）：
  1. 那三行当时定成不能拖（`pasteboardWriterForItem` 给 nil），但 `canDragRows` 没拦：按住它往下拉时，系统把**别的选中行**（当时开着的那本书）
     当成被拖的东西拖走了；
  2. `.gap` 反馈会把被拖的行**藏起来**，等数据源用 `moveItem` 动画挪完再放出来；我们放下后是**整树重建**（`reloadData`），
     藏起来的行视图被复用到了「收藏」那一行上 → 空白。
- 改法：
  - 反馈改成侧栏列表默认的插入线（`.sourceList`），不藏任何行；
  - `SidebarOutlineView.canDragRows` 拦一道：按下的那一行和要拖的每一行都得能拖、且在同一组，否则拖不起来（照常拖选）；
  - 拖动期间工作区变了不重建侧栏，拖完补一次（`draggingRows` / `reloadAfterDrag`）；
  - 用户既然去拖「收藏」，习题顶层的全部 / 错题本 / 收藏也改成能拖（同「各个分组内都能拖」的字面意思）。
