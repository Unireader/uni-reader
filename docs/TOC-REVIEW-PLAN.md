# 自建目录 + 回顾点（2026-11-26）

> 用户原话：「做一下非修改性 toc 支持，pdf 有的没有目录，但是不希望修改 pdf，我们可以直接生成 toc，agent 等地方都能读取」；
> 「pdf 的定期回顾功能，我可以在 pdf 的某个位置添加，不一定需要指定时间，可以一次性设置好几个同一个标签的定期回顾（每个可以备注），
> 下次可以快速筛选；也可以做增量：回顾-1 期、回顾-2 期……回顾-n 期，n 自己设」。
>
> 同日用户定的四件事：期号是**每个回顾点各记一个、看完往后推**；目录**手动编辑 + Agent 生成都要**；
> PDF 本身有目录时**自建的优先、可切回原目录**；这一轮**只做 Mac + MCP**（安卓下一轮）。

## 1. 存储：都放 `note` 表，不改表、不升 schema

| 类型 | kind | 列 | payload |
|---|---|---|---|
| 自建目录项 | 7 | `page` = 起始页（0 起），`anchor_y` = 页内位置，其余锚点 0 | `{"title","level","seq"}` |
| 回顾点 | 8 | 同上 | `{"tag","remark","period","reviews","last"}` |

- `level` 0 起（0 = 第一级），最多 5；`seq` = 同一位置几项的先后。树不另存父子关系：按「页 → 页内位置 → seq」排好，
  `level` 就是先序拍平的深度，用栈还原（`CustomTOCItem.entries`）。跳级（第一级后面直接第三级）照样挂在前一项下。
- `period` ≥ 1；`reviews` = 看过几次；`last` = 最后一次看完的时间（ISO 8601，可缺）。
- 同书签 kind=5 的先例：同步、离线镜像、回收站、删文档级联全部原样继承。
  🔴 旧版各端（安卓、服务器网页）读 `note` 表**都按指定 kind 读**（已逐处核过：安卓 `WorkspaceSearch` / 服务器 `pageMarks` 都过滤 kind），
  多出来的行看不见也不碰，所以不升 schema、不用 Mac / 安卓 / 服务器一起发布。
- 回收站 `TrashStore.Counts` 加了 `tocEntry` / `review` 两个计数（`Trash.archiveNotes` 要求归档条数 = 要删的条数，不加就删不掉）。

## 2. 自建目录（Mac）

### 2.1 生效规则
- `DocSession.toc` = **当前生效的目录**：有自建目录且没切回 → 自建目录；否则 PDF 自带目录（`pdfTOC`，后台解析）。只经 `applyTOC()` 写。
- 所有消费方（Inspector 目录页、平板 `toc` 广播、「所在章节」提示、跳转历史、搜索结果卡）因此自动用上自建目录。
- 「切回 PDF 目录」只在内存（`tocShowsPDF`），换文档复位；加了新的自建条目会自动切回自建目录（不然加了看不见）。
- 参考窗：有自建目录就用自建目录，只读不切换。

### 2.2 读写
- 全部直接写库（`WorkspaceManager+TOCReview.swift`），写完发 `.customTOCDidChange`，开着这篇的标签重读——不走书签那套「会话列表 + 增量对账」。
- 删除 / 清空 / 整份替换（复制 PDF 目录、Agent `set_toc`）一律**先归档进回收站再删**（红线 11）；整份替换在一个事务里删旧写新。
- 同步拉到 kind=7 的行 → `DocTabModel.applyRemote` 重读。

### 2.3 界面
- Inspector 目录页左下角下拉：显示自建目录 / 显示 PDF 自带目录、在当前位置添加目录项…、复制 PDF 目录来修改、清空自建目录…
- 自建目录显示时，条目右键：编辑…（名字 + 层级）、升一级、降一级、删除。
- 阅读区右键「在此添加目录项…」：落点 = 右键处；默认层级 = 前面最近那项的层级。
- 编辑框用系统 `NSAlert` + 附加视图（`TOCReviewSheets`），名字空着时确定键是灰的。

## 3. 回顾点（Mac）

- 阅读区右键「在此添加回顾点…」：标签（下拉里有工作区用过的标签，默认上次用的）+ 期号（默认上次用的）+ 备注。连着给同一个标签加好几处不用重填。
- 页左缘一枚淡紫小圆钉（同一处几枚往下错开）；点它弹气泡：标签 · 第 n 期、备注、「看完，推到第 n+k 期」、编辑…、删除。
- Inspector「笔记」页新分区「回顾」：
  - 筛选：范围（本文档 / 整个工作区）、标签、期号；「看完后推 k 期」的 k 在这里选（1/2/3/5/7/10 或自定义，存 UserDefaults `reviewAdvanceStep`）。
  - 卡片：标签、第 n 期、备注、页码（整个工作区时带书名）、已回顾几次；按钮：看完后推、编辑、删除。
  - 点卡片：本篇就地跳；别的文档经 `AppDelegate.showDocument` 打开再跳。
  - 排序：期号 → 书名 → 页 → 页内位置。
- 写完发 `.reviewMarksDidChange`；同步拉到 kind=8 的行（或任何 note 删除行）、回收站放回都发这条，整个工作区的列表跟着重读。

## 4. MCP

| 工具 | 级别 | 说明 |
|---|---|---|
| `get_document` | 读 | 新参数 `toc_source`（auto / custom / pdf，默认 auto = 有自建目录就返回它）；返回多了 `toc_source`、`has_custom_toc`、`has_pdf_toc`，自建目录的条目多 `id` / `level`（1 起）/ `y` |
| `set_toc` | 写 | 整份替换自建目录：`entries[{title, page(1 起), y?, level?(1 起)}]`，`[]` = 清空；旧的进回收站。页码越界整批拒绝 |
| `list_reviews` | 读 | 按文档 / 标签 / 期号 / `max_period` 筛；返回全部标签 |
| `add_reviews` | 写 | 一篇文档里加若干回顾点 |
| `update_reviews` | 写 | 改标签 / 备注 / 期号；`advance` = 看完后推（期号 + advance，回顾次数 + 1） |
| `delete_reviews` | 删 | 按 id 删（全长或 8 位前缀），按文档分批进回收站 |

实现在 `Sources/MCP/MCPTools+TOCReview.swift`；服务说明（`MCPServer.swift`）补了两句。

## 6. 没做 / 下一轮

- 安卓模式1：不显示自建目录与回顾点（数据照常同步、不会被动到）。模式2 平板的目录来自 Mac 广播，所以**已经能看到自建目录**。
- 服务器网页阅读器：不显示。
- 全工作区搜索（`search`）还不收录回顾点备注与自建目录名。
- 回顾没有「当前第几期」的全局概念：期号只是每个点自己的数字，按期号筛选就是看那一期。
