# 笔迹点集二进制（schema v18，`BINARY-INK-PLAN.md §2`）的跨端向量。
# 格式：每行 `点集|十六进制`；点集 = 分号分隔的 `x,y,z`（空 = 零个点）。
# 十六进制 = `u8 版本 01` + 每点 f32 x / y / z 小端。浮点位型用 Python `struct.pack('<f', v)` 手算，不依赖任一端实现。
