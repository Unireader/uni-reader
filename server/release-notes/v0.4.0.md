## 中文

### 新功能
- 数据版本升到 25：新增「Agent 记忆」（Agent 为以后的对话记下的简短事实）和「Agent 对话记录」（Agent 面板里每一轮的提问与回复）两类数据，经服务器在各设备之间同步。

### 改进
- 计算同步用的数据指纹更快，大工作区每次同步等得更短。

### 下载哪一个
- Linux，ARM 64 位（比如 RK3399、树莓派 4 及更新的板子）：`unireader-server-0.4.0-linux-aarch64.tar.gz`
- Linux，x86-64：`unireader-server-0.4.0-linux-x86_64.tar.gz`
- macOS，Apple 芯片（macOS 14 起）：`unireader-server-0.4.0-macos-arm64.tar.gz`（没有签名和公证，解压后先执行 `xattr -dr com.apple.quarantine <解压出的文件夹>`）
- `SHA256SUMS.txt` 是各个文件的校验和。

### 升级
- 停掉服务 → 换掉 `unireader-server` 这个文件 → 再启动。数据目录不用动，工作区会自动升到新的数据版本。
- `unireader-server --version` 显示 0.4.0 就是换好了。
- **先升级服务器，再更新 Mac App**（带 Agent 记忆的那一版起）。（2026-11-13 更正）服务器只接受数据版本和它一样的 App 上传改动：只升了服务器时，旧版 App 只能下载、不能上传；只升了 App 时也一样。

## English

### New
- Data version is now 25: two new kinds of data, Agent memories (short facts an agent keeps for later conversations) and Agent conversation history (each question and reply in the Agent panel), sync between devices through the server.

### Improved
- The data fingerprints used for syncing are computed faster, so each sync of a large workspace takes less time.

### Which file to download
- Linux, 64-bit ARM (RK3399, Raspberry Pi 4 and newer boards, for example): `unireader-server-0.4.0-linux-aarch64.tar.gz`
- Linux, x86-64: `unireader-server-0.4.0-linux-x86_64.tar.gz`
- macOS, Apple silicon (macOS 14 or later): `unireader-server-0.4.0-macos-arm64.tar.gz` (not signed or notarized; after unpacking, run `xattr -dr com.apple.quarantine <unpacked folder>` first)
- `SHA256SUMS.txt` lists the checksums of the files.

### Upgrading
- Stop the service → replace the `unireader-server` file → start it again. The data folder stays as it is, and workspaces are upgraded to the new data version automatically.
- `unireader-server --version` should show 0.4.0.
- **Upgrade the server before updating the Mac app** (the version with Agent memories or later). (Corrected 2026-11-13) The server only accepts uploads from an app with the same data version as itself: if only the server is upgraded, older apps can download but can't upload, and the same goes the other way round.
