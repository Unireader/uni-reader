## 中文

### 新功能
- 网页（静态 HTML 课件）经服务器在各设备之间同步：课件的文件（HTML、图片、样式、脚本、视频）和课件里保存的学习进度都会同步。

### 下载哪一个
- Linux，ARM 64 位（比如 RK3399、树莓派 4 及更新的板子）：`unireader-server-0.8.0-linux-aarch64.tar.gz`
- Linux，x86-64：`unireader-server-0.8.0-linux-x86_64.tar.gz`
- macOS，Apple 芯片（macOS 14 起）：`unireader-server-0.8.0-macos-arm64.tar.gz`（没有签名和公证，解压后先执行 `xattr -dr com.apple.quarantine <解压出的文件夹>`）
- `SHA256SUMS.txt` 是各个文件的校验和。

### 升级
- 停掉服务 → 换掉 `unireader-server` 这个文件 → 再启动。数据目录不用动。
- `unireader-server --version` 显示 0.8.0 就是换好了。
- 数据版本没有变（仍是 28），旧版 App 照常能同步。要在设备之间同步网页，Mac App 需要 0.3.35 或更新、安卓版需要 0.3.24 或更新；旧版服务器只同步网页的条目，不传课件文件。

## English

### New
- Web pages (static HTML lessons) sync between devices through the server: the lesson files (HTML, images, styles, scripts, videos) and the progress the lessons save.

### Which file to download
- Linux, 64-bit ARM (RK3399, Raspberry Pi 4 and newer boards, for example): `unireader-server-0.8.0-linux-aarch64.tar.gz`
- Linux, x86-64: `unireader-server-0.8.0-linux-x86_64.tar.gz`
- macOS, Apple silicon (macOS 14 or later): `unireader-server-0.8.0-macos-arm64.tar.gz` (not signed or notarized; after unpacking, run `xattr -dr com.apple.quarantine <unpacked folder>` first)
- `SHA256SUMS.txt` lists the checksums of the files.

### Upgrading
- Stop the service → replace the `unireader-server` file → start it again. The data folder stays as it is.
- `unireader-server --version` should show 0.8.0.
- The data version is unchanged (still 28), so older apps keep syncing. To sync web pages between devices you need the Mac app 0.3.35 or later and the Android app 0.3.24 or later; an older server syncs the web page entries but not the lesson files.
