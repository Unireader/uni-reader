## 中文

### 新功能
- 笔记文件同步：工作区 Notes 里的 Markdown 笔记和附件，现在经服务器在各设备之间同步。两台设备改了同一篇时，服务器不会合并或覆盖，由设备另存冲突副本；被覆盖的旧版本和被删的文件会先放进服务器的回收站（保留 90 天）。
- 引用笔记目录的镜像：有这个目录的设备把它传上来，其他设备可以只读查看。
- 实时通知：设备开着工作区时可以挂着等服务器的通知，别的设备一有改动就能马上收到（长轮询，普通 HTTP，不需要额外设置，反向代理也能用）。
- 数据版本升到 24（习题标签）。

### 修复
- 在用户 NAS 这类 mergerfs 文件系统上，修改已有的笔记会失败。已修好；服务器遇到意外错误时也会写进日志，方便排查。

### 下载哪一个
- Linux，ARM 64 位（比如 RK3399、树莓派 4 及更新的板子）：`unireader-server-0.3.0-linux-aarch64.tar.gz`
- Linux，x86-64：`unireader-server-0.3.0-linux-x86_64.tar.gz`
- macOS，Apple 芯片（macOS 14 起）：`unireader-server-0.3.0-macos-arm64.tar.gz`（没有签名和公证，解压后先执行 `xattr -dr com.apple.quarantine <解压出的文件夹>`）
- `SHA256SUMS.txt` 是各个文件的校验和。

### 升级
- 停掉服务 → 换掉 `unireader-server` 这个文件 → 再启动。数据目录不用动，工作区会自动升到新的数据版本。
- `unireader-server --version` 显示 0.3.0 就是换好了。
- **先升级服务器，再更新 Mac App**（UniReader macOS 0.3.20 起）。旧版 App 连新服务器照常；新版 App 连旧服务器会推不上去。

## English

### New
- Notes file sync: the Markdown notes and attachments in a workspace's Notes folder now sync between devices through the server. When two devices edit the same note, the server doesn't merge or overwrite; the devices save a conflict copy. Replaced older versions and deleted files go to the server's recycle area first (kept for 90 days).
- Mirror of a referenced notes folder: a device that has the folder uploads it, and other devices can read it, read-only.
- Live notifications: a device with a workspace open can wait for the server to tell it when another device changes something, and pick the change up right away (long polling over plain HTTP: no extra setup, and it works behind a reverse proxy).
- Data version is now 24 (question tags).

### Fixed
- Editing an existing note failed on mergerfs file systems like the one on a NAS. Fixed; the server also writes unexpected errors to its log now, so problems are easier to track down.

### Which file to download
- Linux, 64-bit ARM (RK3399, Raspberry Pi 4 and newer boards, for example): `unireader-server-0.3.0-linux-aarch64.tar.gz`
- Linux, x86-64: `unireader-server-0.3.0-linux-x86_64.tar.gz`
- macOS, Apple silicon (macOS 14 or later): `unireader-server-0.3.0-macos-arm64.tar.gz` (not signed or notarized; after unpacking, run `xattr -dr com.apple.quarantine <unpacked folder>` first)
- `SHA256SUMS.txt` lists the checksums of the files.

### Upgrading
- Stop the service → replace the `unireader-server` file → start it again. The data folder stays as it is, and workspaces are upgraded to the new data version automatically.
- `unireader-server --version` should show 0.3.0.
- **Upgrade the server before updating the Mac app** (UniReader macOS 0.3.20 or later). An older app works with a new server as usual; a new app can't push to an old server.
