## 中文

### 修复
- 每本书的默认笔迹图层现在各管各的。以前所有书的默认图层共用一条记录：打开一本书时会把另一本书默认图层的名字、颜色、显示状态改回去，而且每次打开都会多同步一处改动。
- 网页阅读器按新的规则认默认图层，显示和隐藏照旧。

### 下载哪一个
- Linux，ARM 64 位（比如 RK3399、树莓派 4 及更新的板子）：`unireader-server-0.9.0-linux-aarch64.tar.gz`
- Linux，x86-64：`unireader-server-0.9.0-linux-x86_64.tar.gz`
- macOS，Apple 芯片（macOS 14 起）：`unireader-server-0.9.0-macos-arm64.tar.gz`（没有签名和公证，解压后先执行 `xattr -dr com.apple.quarantine <解压出的文件夹>`）
- `SHA256SUMS.txt` 是各个文件的校验和。

### 升级
- 停掉服务 → 换掉 `unireader-server` 这个文件 → 再启动。数据目录不用动。
- `unireader-server --version` 显示 0.9.0 就是换好了。
- 🔴 数据版本从 28 升到 29：换了这一版之后，Mac App 和安卓版也要换成支持 29 的新版才能同步；旧版 App 连上会提示版本不一致、先不同步，本机的改动留着，换了新版再推上去。

## English

### Fixed
- Each book now has its own default ink layer. Before, all books shared one record for it: opening one book reset the name, colour and visibility of another book's default layer, and every open synced one extra change.
- The web reader recognises default layers under the new rule; showing and hiding layers works as before.

### Which file to download
- Linux, 64-bit ARM (RK3399, Raspberry Pi 4 and newer boards, for example): `unireader-server-0.9.0-linux-aarch64.tar.gz`
- Linux, x86-64: `unireader-server-0.9.0-linux-x86_64.tar.gz`
- macOS, Apple silicon (macOS 14 or later): `unireader-server-0.9.0-macos-arm64.tar.gz` (not signed or notarized; after unpacking, run `xattr -dr com.apple.quarantine <unpacked folder>` first)
- `SHA256SUMS.txt` lists the checksums of the files.

### Upgrading
- Stop the service → replace the `unireader-server` file → start it again. The data folder stays as it is.
- `unireader-server --version` should show 0.9.0.
- 🔴 The data version goes from 28 to 29: after this upgrade the Mac app and the Android app also need versions that support 29 to sync. Older apps are told the versions don't match and hold off; local changes stay on the device and are uploaded once the app is updated.
