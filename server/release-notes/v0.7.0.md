## 中文

### 新功能
- 数据版本升到 28：习题可以不关联 PDF（放在分组里），经服务器在各设备之间同步。
- 一台设备删掉一篇有习题的 PDF 时，题目和做题记录会保留，其它设备同步后也都还在。

### 下载哪一个
- Linux，ARM 64 位（比如 RK3399、树莓派 4 及更新的板子）：`unireader-server-0.7.0-linux-aarch64.tar.gz`
- Linux，x86-64：`unireader-server-0.7.0-linux-x86_64.tar.gz`
- macOS，Apple 芯片（macOS 14 起）：`unireader-server-0.7.0-macos-arm64.tar.gz`（没有签名和公证，解压后先执行 `xattr -dr com.apple.quarantine <解压出的文件夹>`）
- `SHA256SUMS.txt` 是各个文件的校验和。

### 升级
- 停掉服务 → 换掉 `unireader-server` 这个文件 → 再启动。数据目录不用动，工作区会自动升到新的数据版本。
- `unireader-server --version` 显示 0.7.0 就是换好了。
- **服务器和各个设备上的 App 要一起升级**：Mac App 要 0.3.32 或更新，安卓版要 0.3.23 或更新。只升了一边时，没升的那一边只能下载、不能上传。

## English

### New
- Data version is now 28: exercises no longer have to belong to a PDF (they are kept in groups), and they sync between devices through the server.
- When one device deletes a PDF that has exercises, the questions and your practice history are kept, on the other devices too once they sync.

### Which file to download
- Linux, 64-bit ARM (RK3399, Raspberry Pi 4 and newer boards, for example): `unireader-server-0.7.0-linux-aarch64.tar.gz`
- Linux, x86-64: `unireader-server-0.7.0-linux-x86_64.tar.gz`
- macOS, Apple silicon (macOS 14 or later): `unireader-server-0.7.0-macos-arm64.tar.gz` (not signed or notarized; after unpacking, run `xattr -dr com.apple.quarantine <unpacked folder>` first)
- `SHA256SUMS.txt` lists the checksums of the files.

### Upgrading
- Stop the service → replace the `unireader-server` file → start it again. The data folder stays as it is, and workspaces are upgraded to the new data version automatically.
- `unireader-server --version` should show 0.7.0.
- **Upgrade the server and the apps on all your devices together**: the Mac app needs 0.3.32 or later, and the Android app 0.3.23 or later. If only one side is upgraded, the side that wasn't can download but can't upload.
