## 中文

### 改进
- 同步 Agent 上下文：UniReader macOS 0.3.19 起可以把一段 Agent 对话的摘要存成「上下文」，换一个 Agent 接着聊。这些上下文现在经服务器同步到其他设备。旧版服务器会把它们丢掉。

### 下载哪一个
- Linux，ARM 64 位（比如 RK3399、树莓派 4 及更新的板子）：`unireader-server-0.2.2-linux-aarch64.tar.gz`
- Linux，x86-64：`unireader-server-0.2.2-linux-x86_64.tar.gz`
- macOS，Apple 芯片（macOS 14 起）：`unireader-server-0.2.2-macos-arm64.tar.gz`（没有签名和公证，解压后先执行 `xattr -dr com.apple.quarantine <解压出的文件夹>`）
- `SHA256SUMS.txt` 是各个文件的校验和。

### 升级
- 停掉服务 → 换掉 `unireader-server` 这个文件 → 再启动。数据目录不用动。
- `unireader-server --version` 显示 0.2.2 就是换好了。
- 先升级服务器，再更新 Mac App。如果在升级服务器之前就存了上下文，要在 Mac 上把它改一下（比如改个字再改回来），才会传到服务器。

## English

### Improvements
- Syncs Agent contexts: from UniReader macOS 0.3.19 you can save a summary of an Agent chat as a "context" and carry on with a different agent. These contexts now sync to your other devices through the server. Older servers drop them.

### Which file to download
- Linux, 64-bit ARM (RK3399, Raspberry Pi 4 and newer boards, for example): `unireader-server-0.2.2-linux-aarch64.tar.gz`
- Linux, x86-64: `unireader-server-0.2.2-linux-x86_64.tar.gz`
- macOS, Apple silicon (macOS 14 or later): `unireader-server-0.2.2-macos-arm64.tar.gz` (not signed or notarized; after unpacking, run `xattr -dr com.apple.quarantine <unpacked folder>` first)
- `SHA256SUMS.txt` lists the checksums of the files.

### Upgrading
- Stop the service → replace the `unireader-server` file → start it again. The data folder stays as it is.
- `unireader-server --version` should show 0.2.2.
- Upgrade the server before updating the Mac app. A context you saved before the server was upgraded reaches the server only after you edit it once on the Mac (change a letter and change it back, for example).
