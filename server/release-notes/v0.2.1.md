## 中文

### 改进
- 同步侧栏里拖出来的顺序：UniReader macOS 0.3.17 起可以在侧栏拖动排序，画板、Markdown 笔记和习题的顺序现在经服务器同步到其他设备。旧版服务器会把这些顺序丢掉，设备之间看到的顺序不一致。

### 下载哪一个
- Linux，ARM 64 位（比如 RK3399、树莓派 4 及更新的板子）：`unireader-server-0.2.1-linux-aarch64.tar.gz`
- Linux，x86-64：`unireader-server-0.2.1-linux-x86_64.tar.gz`
- macOS，Apple 芯片（macOS 14 起）：`unireader-server-0.2.1-macos-arm64.tar.gz`（没有签名和公证，解压后先执行 `xattr -dr com.apple.quarantine <解压出的文件夹>`）
- `SHA256SUMS.txt` 是各个文件的校验和。

### 升级
- 停掉服务 → 换掉 `unireader-server` 这个文件 → 再启动。数据目录不用动。
- `unireader-server --version` 显示 0.2.1 就是换好了。
- 升级之前已经在 Mac 上排好的顺序，下次在 Mac 上再拖动一次，才会传到服务器。

## English

### Improvements
- Syncs the order you set by dragging in the sidebar: from UniReader macOS 0.3.17 you can drag to reorder the sidebar, and the order of boards, Markdown notes and exercises now syncs to your other devices through the server. Older servers drop this order, so devices end up showing different orders.

### Which file to download
- Linux, 64-bit ARM (RK3399, Raspberry Pi 4 and newer boards, for example): `unireader-server-0.2.1-linux-aarch64.tar.gz`
- Linux, x86-64: `unireader-server-0.2.1-linux-x86_64.tar.gz`
- macOS, Apple silicon (macOS 14 or later): `unireader-server-0.2.1-macos-arm64.tar.gz` (not signed or notarized; after unpacking, run `xattr -dr com.apple.quarantine <unpacked folder>` first)
- `SHA256SUMS.txt` lists the checksums of the files.

### Upgrading
- Stop the service → replace the `unireader-server` file → start it again. The data folder stays as it is.
- `unireader-server --version` should show 0.2.1.
- An order you set on your Mac before upgrading reaches the server the next time you drag something in that group on the Mac.
