## 中文

### 新功能
- 数据版本升到 26：新增「日程」（日历 + 待办：计划和每一天要做的事），经服务器在各设备之间同步。

### 更正
- 0.4.0 的说明里写「旧版 App 连新服务器照常」，这句不对。服务器只接受数据版本和它一样的 App 上传改动；版本不一样时还能从服务器下载，但上传会被拒绝，并提示先升级 App 或先升级服务器。

### 下载哪一个
- Linux，ARM 64 位（比如 RK3399、树莓派 4 及更新的板子）：`unireader-server-0.5.0-linux-aarch64.tar.gz`
- Linux，x86-64：`unireader-server-0.5.0-linux-x86_64.tar.gz`
- macOS，Apple 芯片（macOS 14 起）：`unireader-server-0.5.0-macos-arm64.tar.gz`（没有签名和公证，解压后先执行 `xattr -dr com.apple.quarantine <解压出的文件夹>`）
- `SHA256SUMS.txt` 是各个文件的校验和。

### 升级
- 停掉服务 → 换掉 `unireader-server` 这个文件 → 再启动。数据目录不用动，工作区会自动升到新的数据版本。
- `unireader-server --version` 显示 0.5.0 就是换好了。
- **服务器和各个设备上的 App 要一起升级**：Mac App 要 0.3.27 或更新，安卓版要 0.3.19 或更新。只升了一边时，没升的那一边只能下载、不能上传。

## English

### New
- Data version is now 26: a new kind of data, the schedule (calendar and to-dos: plans and what to do each day), syncs between devices through the server.

### Correction
- The 0.4.0 notes said "an older app works with a new server as usual". That was wrong. The server only accepts uploads from an app with the same data version as itself; with a different version the app can still download from the server, but uploads are refused with a message to update the app or the server first.

### Which file to download
- Linux, 64-bit ARM (RK3399, Raspberry Pi 4 and newer boards, for example): `unireader-server-0.5.0-linux-aarch64.tar.gz`
- Linux, x86-64: `unireader-server-0.5.0-linux-x86_64.tar.gz`
- macOS, Apple silicon (macOS 14 or later): `unireader-server-0.5.0-macos-arm64.tar.gz` (not signed or notarized; after unpacking, run `xattr -dr com.apple.quarantine <unpacked folder>` first)
- `SHA256SUMS.txt` lists the checksums of the files.

### Upgrading
- Stop the service → replace the `unireader-server` file → start it again. The data folder stays as it is, and workspaces are upgraded to the new data version automatically.
- `unireader-server --version` should show 0.5.0.
- **Upgrade the server and the apps on all your devices together**: the Mac app needs 0.3.27 or later, and the Android app 0.3.19 or later. If only one side is upgraded, the side that wasn't can download but can't upload.
