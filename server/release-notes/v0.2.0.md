## 中文

第一个公开发布的服务器程序。

### 这是什么
- 自己运行的 UniReader 服务器：把工作区放到自己的机器（比如 NAS）上，Mac 和安卓平板共用一份。每台设备在本机留一份副本，连不上服务器时照常阅读、书写，连上以后只传改动。
- 在 UniReader App 的 设置 ›「服务器」里填地址和配对码连接；同一网络里的服务器会自动列出来。
- 自带网页阅读器：在浏览器里打开服务器地址、输入配对码，就能看书，看笔迹、高亮和文字笔记，也能手写、整笔擦除、撤销重做、写文字笔记。
- 删掉的工作区在服务器的回收站里留 90 天，可以找回；每小时自动备份有改动的工作区。
- 和 UniReader macOS 0.3.15 一起使用。App 里「从服务器删除」「重命名」服务器上的工作区需要这个版本。

### 下载哪一个
- Linux，ARM 64 位（比如 RK3399、树莓派 4 及更新的板子）：`unireader-server-0.2.0-linux-aarch64.tar.gz`
- Linux，x86-64：`unireader-server-0.2.0-linux-x86_64.tar.gz`
- Linux 版是一个独立的文件，不依赖系统里装的 Swift 或系统库的版本。
- macOS，Apple 芯片（macOS 14 起）：`unireader-server-0.2.0-macos-arm64.tar.gz`。这个程序没有签名和公证，解压后先在终端执行 `xattr -dr com.apple.quarantine <解压出的文件夹>`，否则系统不让运行。
- `SHA256SUMS.txt` 是各个文件的校验和。

### 在 Linux 上安装
1. 解压后把 `unireader-server` 放到比如 `/opt/unireader/`。
2. 先试着运行：`/opt/unireader/unireader-server serve --data /var/lib/unireader --host 0.0.0.0`，启动信息里会显示配对码（默认端口 8790）。以后也可以用 `unireader-server pairing-code --data /var/lib/unireader` 查看。
3. 长期运行：照包里 `unireader-server.service` 开头的说明，装成 systemd 服务。
4. 可选：装 `avahi-utils`，同一网络里的设备就能自动找到服务器；装 `mupdf-tools` 和 `libjpeg-turbo-progs`，网页阅读器就由服务器画好页面再传给浏览器（没装时由浏览器自己加载 PDF）。
5. 服务器用的是不加密的 HTTP：只在家里的网络或 Tailscale 里直接连；要从外网访问，请放在 HTTPS 反向代理（比如 Caddy）后面。

### 升级
- 停掉服务 → 换掉 `unireader-server` 这个文件 → 再启动。数据目录不用动。
- `unireader-server --version` 显示版本号。

## English

The first public release of the server program.

### What it is
- A UniReader server you run yourself: keep your workspaces on your own machine (a NAS, for example) and share them between your Mac and Android tablet. Each device keeps its own copy, so you can keep reading and writing when the server can't be reached; once connected again, only the changes are sent.
- Connect in the UniReader app under Settings › Servers with the server's address and pairing code. Servers on the same network are listed automatically.
- A built-in web reader: open the server's address in a browser and enter the pairing code to read your books and see your ink, highlights and text notes. You can also write by hand, erase whole strokes, undo and redo, and write text notes.
- Deleted workspaces stay in the server's trash for 90 days and can be restored. Workspaces with changes are backed up every hour.
- Use it with UniReader for macOS 0.3.15. Deleting or renaming a workspace on the server from the app needs this version.

### Which file to download
- Linux, 64-bit ARM (for example RK3399, Raspberry Pi 4 and newer boards): `unireader-server-0.2.0-linux-aarch64.tar.gz`
- Linux, x86-64: `unireader-server-0.2.0-linux-x86_64.tar.gz`
- The Linux builds are a single self-contained file. They don't depend on the Swift or system library versions installed on the machine.
- macOS, Apple silicon (macOS 14 or later): `unireader-server-0.2.0-macos-arm64.tar.gz`. It isn't signed or notarized: after unpacking, run `xattr -dr com.apple.quarantine <unpacked folder>` in Terminal, or macOS won't let it run.
- `SHA256SUMS.txt` has the checksums of the files.

### Installing on Linux
1. Unpack it and put `unireader-server` somewhere such as `/opt/unireader/`.
2. Try it first: `/opt/unireader/unireader-server serve --data /var/lib/unireader --host 0.0.0.0`. The startup message shows the pairing code (the default port is 8790). You can see it again later with `unireader-server pairing-code --data /var/lib/unireader`.
3. To keep it running, install it as a systemd service by following the notes at the top of `unireader-server.service` in the package.
4. Optional: install `avahi-utils` so devices on the same network can find the server automatically, and `mupdf-tools` plus `libjpeg-turbo-progs` so the server draws the pages for the web reader (without them, the browser loads the PDF itself).
5. The server uses plain, unencrypted HTTP. Connect to it directly only on your home network or over Tailscale; to reach it from the internet, put it behind an HTTPS reverse proxy such as Caddy.

### Upgrading
- Stop the service, replace the `unireader-server` file, and start it again. The data folder stays as it is.
- `unireader-server --version` shows the version.
