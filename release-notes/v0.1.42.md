## 中文

本版汇总 0.1.41 以来的改动。

### 联网检查更新
- 「UniReader」菜单新增「检查更新…」，设置窗「通用」标签页新增「更新」区块：可以开关自动检查、选检查频率（每小时/每天/每周）、看当前版本和上次检查时间、随时手动「立即检查」。更新包会先校验签名再安装，全程走系统的安装/重启流程。

### 拖选文字新增框选模式
- 设置 › 阅读 › 拖选文字方式，新增「框选」（默认开）：拖出一个矩形，框到哪些字就选哪些字，不再是整行整段；⌘+拖可以叠加出多段不连续的选区，跟 Finder/邮件里的多选一致。不习惯的话可以在设置里切回「流式选择」（起点拖到终点、按阅读顺序选中之间内容，老版本的行为）。

### 修复与改进
- 设置窗补上 ⌘W / ⇧⌘W 关闭快捷键，之前只能点右上角关闭按钮。

## English

This release covers changes since 0.1.41.

### Check for Updates
- The "UniReader" menu now has a "Check for Updates…" item, and Settings › General has a new "Updates" section: toggle automatic checks, pick a check frequency (hourly/daily/weekly), see the current version and last-checked time, and check any time with "Check Now". Update packages are signature-verified before installing, through the system's usual install/restart flow.

### Box Select for Drag-Selecting Text
- Settings › Reading › Drag-select style now has a "Box select" option (on by default): drag out a rectangle and it selects whatever text the rectangle touches, character by character, not whole lines or paragraphs. ⌘-drag adds another box to build up a multi-part selection, same as multi-select in Finder or Mail. Prefer the old behavior? Switch back to "Flow select" in Settings (drag from a start point to an end point, selecting everything in between in reading order).

### Fixes and Improvements
- The Settings window now closes with ⌘W / ⇧⌘W, not just the close button.
