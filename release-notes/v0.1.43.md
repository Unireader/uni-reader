## 中文

本版汇总 0.1.42 以来的改动。

### 框选文字改用 ⌘+拖触发，支持叠加与取消
- 拖选文字默认是流式选择（起点拖到终点，按阅读顺序选中之间内容，老版本的行为）；起手时按住 ⌘ 才切换成框选（拖出一个矩形，框到哪些字就选哪些字）。设置 › 阅读里原来那个「拖选文字方式」开关已经拿掉，改成按键触发。
- ⌘+拖框选永远是叠加在已有选区上，不会换成一份全新的选区——不管这份已有选区是刚才流式选择出来的，还是之前框选出来的。
- 新增设置 › 阅读 ›「框选重复区域」：再框到已经选中的部分时，选「合并」（默认）会保留原有选区、只新增没框到的部分；选「反选」则让重叠的部分互相取消，跟 Finder 图标视图里 ⌘+拖橡皮筋的效果一样。

## English

This release covers changes since 0.1.42.

### Box Select Now Triggered by ⌘-drag, With Add and Remove
- Drag-selecting text now defaults to flow select (drag from a start point to an end point, selecting everything in between in reading order — the old behavior). Hold ⌘ when you start the drag to switch to box select instead (drag out a rectangle and it selects whatever text the rectangle touches). The "Drag-select style" setting under Settings › Reading has been removed in favor of this key-triggered switch.
- ⌘-drag box selection always adds to whatever is already selected, never replaces it — whether that existing selection came from a flow select or an earlier box select.
- New setting, Settings › Reading › "Overlapping box selection": when a new box overlaps text you already selected, "Merge" (the default) keeps the existing selection and only adds the new part, while "Invert" deselects the overlapping part instead — same as ⌘-dragging a fresh rubber band in Finder's icon view.
