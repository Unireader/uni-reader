## 中文

### 自建目录
- 没有目录（或目录不好用）的 PDF 可以自己建一份目录，存在工作区里，不修改 PDF 文件。
- 在页面上右键「在此添加目录项…」，或在检查器「目录」页左下角的菜单里「在当前位置添加目录项…」；条目右键可以编辑名字和层级、升一级、降一级、删除。
- 菜单里还能「复制 PDF 目录来修改」「清空自建目录…」，以及在自建目录和 PDF 自带目录之间切换。删除和清空的内容会进「最近删除」，可以放回。
- Agent 可以读页面后把整份目录写进来，读文档时也会拿到自建目录。

### 回顾
- 在页面上右键「在此添加回顾点…」：填标签、期号和备注，同一个标签可以加在好几处。页面左边缘会出现一个淡紫色小圆点，点开可以「看完，推到下一期」、编辑或删除。
- 检查器「笔记」页新增「回顾」分区：按本文档或整个工作区、标签、期号筛选；「看完后推几期」可以自己设；点别的书里的回顾点会打开那本书并跳到位置。
- Agent 也可以查看、添加、修改和删除回顾点。

### 习题
- 练习页右键或 ⌘C 可以复制题目文字，列表里右键也可以（可多选）；只复制题干和选项，不带答案。

### Markdown 笔记
- 代码块按语言着色：整页编辑、批注框和笔记气泡里都会着色。

### 导航与网页
- 鼠标侧键可以用来导航：后退键 = 返回上一位置，前进键 = 前往下一位置；在网页标签里先走网页自己的前进后退。
- 网页标签切走再切回来不再重新载入，也不会滚回原位抖一下；做题时后台网页不再反复整套重查，更流畅。

## English

### Custom contents
- PDFs without a table of contents (or with a poor one) can get your own contents, stored in the workspace. The PDF file is not changed.
- Right-click a page › Add Contents Entry Here…, or use Add Contents Entry at Current Position… in the menu at the bottom left of the inspector's Contents page. Right-click an entry to edit its title and level, promote or demote it, or delete it.
- The same menu can Copy PDF Contents to Edit, Clear Custom Contents…, and switch between the custom contents and the PDF's own. Deleted or cleared entries go to Recently Deleted and can be put back.
- An agent can read the pages and write the whole contents for you; it also gets the custom contents when it reads a document.

### Reviews
- Right-click a page › Add Review Point Here…: give it a tag, a period number and a remark; one tag can be used in several places. A small lavender dot appears at the left edge of the page; click it to mark it reviewed and move it to a later period, edit it, or delete it.
- New Reviews section on the inspector's Notes page: filter by this document or the whole workspace, by tag and by period. You choose how many periods a point moves when reviewed. Clicking a point in another book opens that book at the spot.
- Agents can list, add, change and delete review points too.

### Exercises
- Copy a question's text with right-click or ⌘C on the practice page, or right-click in the list (multiple selection works). Only the question and choices are copied, not the answer.

### Markdown notes
- Code blocks are coloured by language in the full-page editor, note boxes and note bubbles.

### Navigation and web pages
- The mouse's side buttons navigate: back = go to the previous position, forward = go to the next one. In a web page tab they first go through the page's own history.
- Switching away from a web page tab and back no longer reloads it or jumps back to the saved spot. Background pages no longer re-query everything after each answered question, so practice feels smoother.
