## 中文

### 参考窗
- 弹成独立窗口的参考窗现在可以拖到别的屏幕上，拖动也不再卡顿。它仍然不会被阅读窗盖住；拖阅读窗时它不再跟着移动，阅读窗最小化时它一起收起。

### 公式
- 行内公式不再被裁掉：`a_n` 这类下标的底部、分式的分母现在都能显示完整。含分式的那一行会比普通文字行高一点，不再压到下一行。习题、Markdown 笔记、批注气泡和 Agent 回复里都一样。

### Agent
- Agent 连续输出大量内容时（比如导入习题）占用的处理器明显降低，界面不再发卡。
- 一扇窗口开着几段对话时，在它们之间切换更快。

### 连接服务器
- 同步前检查改动的那一步更快了。

## English

### Reference window
- A reference window opened as a separate window can now be dragged to another display, and dragging it is smooth. It still stays above the reading window; it no longer moves along when you drag the reading window, and it is put away when the reading window is minimized.

### Formulas
- Inline formulas are no longer cut off: the bottom of subscripts such as `a_n` and the denominator of a fraction are shown in full. A line containing a fraction is a little taller than a plain line of text instead of running into the next one. This applies to exercises, Markdown notes, note bubbles and Agent replies alike.

### Agent
- When an agent produces a lot of output in a row (importing exercises, for example), the app uses much less CPU and stays responsive.
- Switching between several conversations in one window is faster.

### Servers
- Checking for changes before a sync is faster.
