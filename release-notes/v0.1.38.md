## 中文

本版汇总 0.1.35 以来的改动。

### 笔记
- **支持 Markdown**：笔记编辑器和页面上的笔记卡片都按 Markdown 显示，编辑器里按 ⌘↩ 保存。在「设置 › 阅读」里可以调整卡片正文字号、编辑框字号，以及卡片的最小和最大宽度；较短的笔记会按内容自动收窄。
- **支持 LaTeX 公式**：`$…$` 为行内公式，`$$…$$` 为单独成行的公式。
- **笔记卡片可以拖动和调整大小**：按住卡片任意位置拖动可以移动，拖动四边或四角可以改大小，位置和大小会保存，也可以撤销。内容超出卡片高度时在卡片内滚动。右键菜单新增「复制笔记正文」和「恢复卡片默认大小和位置」。
- **图片笔记**：在页面上按住 ⌥⇧ 拖出一个框，可以把这块区域存为图片笔记；也可以把图片文件拖到页面上、在右键菜单选「在此导入图片…」，或者按 ⌘V 粘贴图片。图片保存在工作区里，不再被任何笔记使用的图片会在 30 天后自动删除；「设置 › 通用」里可以查看占用空间并立即清理。
- 笔记卡片默认保持固定大小，不随页面缩放；需要随页面缩放时，在「设置 › 阅读」里打开「笔记气泡跟随页面缩放」。

### 高亮
- 选中文字后按 **h** 高亮，按 **n** 添加文字笔记；按 h 时使用上一次用过的颜色。
- 高亮新增两种样式：**画线**（⇧H）和**画框**（⌥H）。右键菜单、高亮弹出框和侧边栏都可以更换样式和颜色。
- 在高亮弹出框里选「添加批注…」可以把高亮转换成文字笔记（保存后原高亮由这条笔记取代）；文字笔记也可以单独设置颜色和样式。
- 单击高亮时弹出框立即出现，不再有延迟。

### 参考窗
- 参考窗可以「弹出为独立窗口」：独立窗口始终显示在阅读窗口上方，并跟随阅读窗口移动；也可以随时「改为窗口内置」，切换时保留滚动位置和缩放比例。
- 新增快捷键 ⌥⌘R，用来打开或关闭参考窗。

### 快捷键
- 新增「设置 › 快捷键」：大部分快捷键可以自定义，支持逐条或全部恢复默认。新建、打开、关闭、撤销、复制、粘贴、查找、退出等基础命令，以及 1–9 选笔，不可更改。
- ⌘⇧A 改为显示或隐藏 AI 面板。

### MCP 服务（供 AI Agent 使用）
- App 内置 MCP 服务，在「设置 › Agent」里开启。默认只允许本机访问（127.0.0.1:8773）；也可以允许局域网访问，但这时必须设置口令。
- Claude Code、Codex 等 Agent 可以通过它查看你正在读的工作区、文档和页码，打开文档，读取页面文字，搜索，获取页面图片，列出高亮和笔记，以及跳转到指定页。
- 打开「允许 Agent 写入」后，Agent 还可以添加书签、文字笔记和高亮，导入 PDF，新建工作区，以及发起 OCR。Agent 写的笔记会带一个终端图标。Agent 不能删除任何内容。

### `unireader://` 链接
- 新增 `unireader://open?...` 链接，点击后直接打开指定的工作区、文档和页码，并可展开指定的笔记，方便从 Obsidian 等笔记软件跳回原文。MCP 返回的文档、批注和阅读位置都附带对应链接。
- 仓库附带一份 Obsidian 导出说明（`skills/unireader-obsidian-export`），供 Agent 把批注导出成 Obsidian 笔记。

### 修复与改进
- 大幅降低阅读窗口和参考窗的内存占用：连接平板连续滚动时，内存不再快速上涨（实测从 1.0–1.7 GB 降到约 185 MB）。
- 点击阅读区会把键盘焦点交回阅读区：搜索框不会一直占用键盘，AI 面板打开时也能用 ⌘C 复制 PDF 文字。
- 单击即可取消文字选择，不用再等待双击判定的时间。

### 已知问题
- 平板采集页和安卓端的笔记仍显示 Markdown 原文，公式也显示为源码。
- 少数 LaTeX 命令暂不支持，会原样显示公式源码。

## English

This release covers changes since 0.1.35.

### Notes
- **Markdown support**: the note editor and the note cards on the page now render Markdown. Press ⌘↩ in the editor to save. In Settings › Reading you can set the card text size, the editor text size, and the minimum and maximum card width; short notes shrink to fit their content.
- **LaTeX formulas**: `$…$` for inline formulas, `$$…$$` for formulas on their own line.
- **Movable, resizable note cards**: drag anywhere on a card to move it, or drag an edge or corner to resize it. Position and size are saved and can be undone. Content taller than the card scrolls inside the card. The context menu adds "Copy Note Text" and "Reset Card Size and Position".
- **Image notes**: hold ⌥⇧ and drag a box on a page to save that area as an image note. You can also drop an image file onto a page, choose "Import Image Here…" from the context menu, or paste an image with ⌘V. Images are stored in the workspace; images no longer used by any note are deleted after 30 days. Settings › General shows the space used and has a "Clean Up Now" button.
- Note cards now keep a fixed size by default and do not scale with the page. Turn on "Note bubbles follow page zoom" in Settings › Reading to make them scale.

### Highlights
- With text selected, press **h** to highlight or **n** to add a text note. h uses the color you used last.
- Two new highlight styles: **Underline** (⇧H) and **Box** (⌥H). Change the style and color from the context menu, the highlight popover, or the sidebar.
- Choose "Add Note…" in the highlight popover to turn a highlight into a text note (once saved, the note replaces the highlight). Text notes can also have their own color and style.
- Clicking a highlight now opens its popover immediately, without the previous delay.

### Reference Window
- The reference window can be opened as a separate window ("Open as Separate Window"). It stays above the reader window and moves with it. Switch back any time with "Show Inside the Window"; scroll position and zoom are kept.
- New shortcut ⌥⌘R to show or hide the reference window.

### Keyboard Shortcuts
- New Settings › Shortcuts: most shortcuts can be changed, and you can reset them one by one or all at once. Basic commands (New, Open, Close, Undo, Copy, Paste, Find, Quit, …) and pen selection with 1–9 cannot be changed.
- ⌘⇧A now shows or hides the AI panel.

### MCP Service (for AI agents)
- UniReader includes an MCP service, turned on in Settings › Agent. By default only this Mac can connect (127.0.0.1:8773). You can also allow connections from the local network, which requires setting a password.
- Agents such as Claude Code and Codex can see which workspace, document and page you are reading, open documents, read page text, search, get page images, list highlights and notes, and go to a page.
- With "Allow agents to write" turned on, agents can also add bookmarks, text notes and highlights, import PDFs, create workspaces and start OCR. Notes written by an agent are marked with a terminal icon. Agents can never delete anything.

### `unireader://` Links
- New `unireader://open?...` links open a given workspace, document and page directly, and can expand a given note, so you can jump back to the source from Obsidian or other note apps. Documents, annotations and reading positions returned by MCP include a ready-made link.
- The repository includes Obsidian export instructions (`skills/unireader-obsidian-export`) that an agent can follow to export your annotations as Obsidian notes.

### Fixes and Improvements
- Much lower memory use in the reader and reference windows: memory no longer climbs quickly while scrolling with a tablet connected (measured: from 1.0–1.7 GB down to about 185 MB).
- Clicking the reading area gives keyboard focus back to it: the search field no longer holds on to the keyboard, and ⌘C copies PDF text even while the AI panel is open.
- A single click now clears the text selection right away, without waiting for the double-click interval.

### Known Issues
- The tablet capture page and the Android app still show notes as raw Markdown, and formulas as source text.
- A few LaTeX commands are not supported yet and are shown as source text.
