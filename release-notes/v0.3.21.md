## 中文

### 新功能：在 Agent 输入框里用 @ 引用笔记目录
- 输入 @ 时，候选里多了 Markdown 笔记的目录：每个笔记源本身和其中的各级子目录都在里面，带文件夹图标。打目录名就能找到。
- 发出去后，Agent 能列出这个目录（含子目录）里的笔记并读取。和在侧栏目录上右键「在 Agent 中引用」效果一样。

### 修正
- 用 @ 选 PDF 时，插进输入框的是书名（侧栏上显示的那个），不再是一串编号。复制进工作区的书、从服务器下载的书以前都会出现这种情况。侧栏右键「在 Agent 中引用」PDF 也一样改好了。

## English

### New: Mention a notes folder with @ in the Agent input
- When you type @, the suggestions now include your Markdown notes folders: each notes source and every folder inside it, shown with a folder icon. Type a folder's name to find it.
- Once sent, the agent can list the notes in that folder (and its subfolders) and read them, the same as right-clicking the folder in the sidebar and choosing Reference in Agent.

### Fixes
- Picking a PDF with @ now inserts the book's title (the name shown in the sidebar) instead of a string of letters and numbers. This used to happen with books copied into the workspace and books downloaded from a server. Reference in Agent on a PDF in the sidebar is fixed the same way.
