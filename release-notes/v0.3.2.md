## 中文

### 新功能和改进
- Agent 读取页面文字、搜索、添加高亮和笔记时，改为优先使用 UniReader 自己的 OCR 识别结果，没有识别过的页才用 PDF 自带的文字。扫描版书籍自带的文字常有错字、位置也不准；现在 Agent 加的高亮和你手动划的一样贴合文字，不会再高出一截、压到上下行。
- Agent 现在可以删除高亮、文字笔记、书签和图片笔记（需要在「设置 ▸ Agent」里打开「允许 Agent 写入」）。Agent 一次删掉的内容会作为一条记录进回收站，可以从「文件 ▸ 回收站」放回来；放回时那篇文档如果正开着，会立刻显示出来。

## English

### New features & improvements
- When an agent reads page text, searches, or adds highlights and notes, it now uses UniReader's own OCR text first, and the PDF's built-in text only on pages that haven't been recognized. The built-in text in scanned books often has typos and inaccurate positions; highlights added by an agent now fit the text just like the ones you make by hand, instead of spilling onto the lines above and below.
- Agents can now delete highlights, text notes, bookmarks and image notes (turn on "Allow agents to write" in Settings ▸ Agent). Everything an agent deletes in one go becomes a single item in Recently Deleted, which you can put back from File ▸ Recently Deleted; if that document is open, the restored items show up right away.
