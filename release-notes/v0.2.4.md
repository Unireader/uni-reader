## 中文

### 新功能
- **笔记小窗**：在侧栏右键一篇 Markdown 笔记，选「打开为小窗」，就能在阅读 PDF 的同时在旁边的小窗里记笔记。每篇笔记开一扇，再开同一篇会把已有的小窗提到前面；小窗会记住各篇的位置，工具栏里可以换一篇，或点「在标签页中打开」。
- **Agent 输入框里用 @ 选文件**：输入 `@` 会弹出工作区里的 PDF 和 Markdown 笔记，按最近打开排序，边打字边筛选；用上下键或鼠标选中后，发送时会告诉 Agent 这是哪个文件（只附名字和位置，不附文件内容）。
- **截图后多了「复制图片」**：按住 ⌥ 拖出一块区域，松手后的菜单里可以选问 Agent、复制图片或存为图片笔记；复制的图片按原清晰度生成。按住 ⌥⇧ 拖仍然直接存为图片笔记。

### 改进
- Markdown 笔记切到别的标签页再切回来，会停在原来的滚动位置。
- 笔记文件在 UniReader 外面被修改（比如在 Obsidian 里编辑）后，打开着的笔记会自动换成新内容；如果这边还有没保存的输入，以这边为准。笔记目录里新增、删除或改名文件，侧栏也会自动刷新。
- Agent 面板里的图片缩略图改为统一的圆角方块；鼠标停在上面会弹出预览，单击可以打开大图查看；移除按钮移到左上角，在浅色图片上也看得清。
- 给外部 Agent 用的 MCP 服务：可以只修改 Markdown 笔记里的某几处而不用整篇重写，可以按行分页读取、在笔记里搜索、查看标题大纲，也可以列出工作区里的全部笔记；笔记不用先打开就能读写，笔记小窗里的内容也能读到。

## English

### New
- **Note windows**: right-click a Markdown note in the sidebar and choose Open in Small Window to keep notes next to the PDF you are reading. Each note gets one window; opening the same note again brings its window to the front. Each window remembers its position, and its toolbar lets you switch to another note or choose Open in Tab.
- **@ to pick files in the Agent input**: typing `@` shows the PDFs and Markdown notes in the workspace, most recently opened first, filtered as you type. Pick one with the arrow keys or the mouse, and when you send, the Agent is told which file you mean (only its name and location are attached, not its contents).
- **Copy Image after a snip**: ⌥-drag over an area and the menu that appears when you let go now offers Ask Agent, Copy Image and Save as Image Note. Copied images are rendered at full resolution. ⌥⇧-drag still saves an image note directly.

### Improvements
- Switching away from a Markdown note tab and back keeps your scroll position.
- When a note file is changed outside UniReader (for example in Obsidian), the open note updates to the new content; if you have unsaved typing, your local text is kept. Adding, deleting or renaming files in note folders refreshes the sidebar automatically.
- Image thumbnails in the Agent panel are now uniform rounded squares; hover to see a preview and click to open the full image. The remove button moved to the top-left corner and stays visible on light images.
- MCP service for external agents: edit just a few places in a Markdown note instead of rewriting it, read a note page by page with line numbers, search inside a note, see its heading outline, and list every note in the workspace. Notes can be read and written without opening them first, and text in note windows is visible too.
