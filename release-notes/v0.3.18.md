## 中文

### 新功能：给 PDF 改名
- 侧栏里右键一本书，选「重命名…」就能改它的名字。改的是书库里显示的名字（侧栏、标签页、窗口标题），磁盘上的文件名不变。
- 已经打开的标签页会跟着换成新名字；连接服务器的工作区里，新名字会同步到其他设备和网页。

### 修复：改过的 PDF 在其他设备上还是旧的
- 连接服务器的工作区里，给 PDF 加了目录这类直接改动文件的操作之后，打开时弹出「文件已变化」，选「关联为新版本」——之前其他设备和网页仍然拿到旧文件，现在会换成新的。其他设备同步后这本书会显示为未下载，点「从服务器下载」下到的就是新版本（不大的会自动下载）。
- 页数没变时，文字识别结果和扫描页对齐会沿用到新版本，不用重新识别。
- 以前已经这样关联过的书，更新后第一次打开工作区时会自动整理好。

## English

### New: Rename a PDF
- Right-click a book in the sidebar and choose Rename… to change its name. This changes the name shown in the library (sidebar, tabs and window title); the file on disk keeps its name.
- Open tabs switch to the new name right away. In workspaces on a server, the new name syncs to your other devices and the web reader.

### Fix: an edited PDF stayed old on other devices
- In workspaces on a server, after you change a PDF file directly (for example, add a table of contents), opening it shows "File Changed"; if you chose "Link as New Version", other devices and the web reader still got the old file. Now they get the new one. After syncing, the book shows as not downloaded on other devices, and Download from Server gets the new version (smaller files download automatically).
- If the page count didn't change, text recognition results and scanned-page alignment carry over to the new version, so nothing has to be recognized again.
- Books you already linked this way are tidied up automatically the first time you open the workspace after updating.
