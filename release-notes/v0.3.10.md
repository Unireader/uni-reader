## 中文

### 新功能
- 文字识别（OCR）多了一个「本机 OCR 服务（PP-OCRv6）」选项：在「设置 › 阅读」里选中后，识别在你自己的 Mac 上完成，不需要 API Key，也不用联网。需要先启动本机 OCR 服务（项目主页：https://github.com/xVanTuring/ocr-services ），设置页和 OCR 面板里都有可点的链接，设置页还能查看服务是否在线。本机服务和云端的识别结果分开保存，切换引擎后需要按新引擎重新识别。

### 修复
- 整本识别完成后重启 App，OCR 面板里的进度显示成「3 of 14 pages recognized」（只数了当前已载入的页），现在显示实际识别的页数。

### 其他
- Markdown 笔记的渲染引擎更新：编辑区滚到顶部或底部时不再回弹，源码模式不再把代码块当作独立区块。

## English

### New
- Text recognition (OCR) has a new "Local OCR Service (PP-OCRv6)" option. Select it in Settings › Reading and recognition runs on your own Mac, with no API key and no internet needed. Start the local OCR service first (project page: https://github.com/xVanTuring/ocr-services); the Settings page and the OCR panel both have a clickable link, and Settings shows whether the service is online. Results from the local service and the cloud are stored separately, so after switching engines pages are recognized again with the new one.

### Fixes
- After recognizing a whole book and restarting the app, the OCR panel showed something like "3 of 14 pages recognized" (it only counted the pages loaded so far). It now shows the number of pages actually recognized.

### Other
- The Markdown note rendering engine was updated: the editor no longer bounces when scrolled to the top or bottom, and source mode no longer reports code blocks as separate blocks.
