## 中文

### 公式
- 公式里的中文能显示了。写在下标或上标里的中文（如 `$[X]_补$`、`$x_{补码}$`）以前整条显示成原文，现在按公式显示；`\text{…}` 里的中文以前是空白，现在也能看到。下标照 LaTeX 的规矩只取一个字，`x_补码` 只有「补」是下标，整个做下标要写 `x_{补码}`。
- `$x, y$`、`$a,b,c$` 这类用逗号列出几个变量的写法现在按公式显示，不再显示原文。
- 以上在习题、Markdown 笔记、批注气泡和 Agent 回复里都一样。

## English

### Formulas
- Chinese inside a formula is shown. Chinese written as a subscript or superscript (such as `$[X]_补$` or `$x_{补码}$`) used to leave the whole formula as source text; it is now typeset. Chinese inside `\text{…}` used to come out blank and is now visible. As in LaTeX, a subscript takes a single character: in `x_补码` only `补` is lowered; write `x_{补码}` to lower both.
- Variables listed with commas, such as `$x, y$` or `$a,b,c$`, are now typeset as formulas instead of shown as source text.
- This applies to exercises, Markdown notes, note bubbles and Agent replies alike.
