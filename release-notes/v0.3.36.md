## 中文

### Markdown 笔记
- 支持 Obsidian 的 callout 写法：`> [!note] 标题` 显示成带类型颜色、图标和粗体标题的提示框，没写标题时显示类型名，可以嵌套。
- callout 可以折叠：`[!note]-` 默认收起，`[!note]+` 默认展开；点图标或前面的箭头切换，只改变显示，不改笔记内容。
- 引用块里的块公式（`> $$…$$`，单行或多行）按块公式居中显示，引用的竖条不再断开。
- Agent 面板的回复和习题正文里，callout 和引用里的块公式也能正常显示；从笔记复制后粘贴到支持富文本的应用，callout 和引用里的公式会保留。

### 公式
- `aligned` 环境支持两列以上，例如右边再加一组收敛域的级数表，原先整条公式显示成源码。
- 支持 `\\[6pt]` 这类换行后的行距写法，原先 `[6pt]` 会当成文字显示在下一行开头。
- `aligned` 里 `=` 左边的空隙恢复正常；矩阵单元格恢复为标准的文本字号（矩阵里的分式会比之前小一些，与 LaTeX 一致）。

### 网页
- 网页标签顶栏新增「回到首页」按钮：课件的子页面没有返回首页的链接时，可以一键回到首页。

### 画板笔记
- 画板笔记列表按新建时间排列、新的在前，打开某一项不再让它跳到最前面。

### 同步
- 修复：用旧版同步过的设备升级后，网页和课件保存的数据可能一直同步不过来；升级后第一次同步会自动补齐。

## English

### Markdown notes
- Obsidian callouts: `> [!note] Title` shows as a box with the type's color, an icon and a bold title (the type name when no title is given). Callouts can be nested.
- Callouts can fold: `[!note]-` starts collapsed and `[!note]+` starts expanded. Click the icon or the arrow before it to switch; this only changes the display, not the note.
- Display math inside a block quote (`> $$…$$`, on one line or several) is centered like other display math, and the quote bar no longer breaks around it.
- Callouts and display math in quotes also show correctly in Agent replies and exercise text, and are kept when you copy from a note and paste into an app that accepts rich text.

### Math
- The `aligned` environment takes more than two columns, such as a table of series with their intervals of convergence on the right. Such formulas used to show as source.
- Row spacing after a line break, such as `\\[6pt]`, now works. Before, `[6pt]` was printed as text at the start of the next row.
- `=` inside `aligned` has its normal space on the left again, and matrix cells are set at the standard text size again (fractions inside a matrix are a little smaller than before, as in LaTeX).

### Web pages
- A new Go to Start Page button in the web page tab's top bar takes you back to the start page when a lesson's inner pages have no link back.

### Boards
- The board list is ordered by creation time, newest first. Opening a board no longer moves it to the top.

### Sync
- Fixed: on a device that had synced with an older version, web pages and the data lessons save could fail to sync after upgrading. The first sync after upgrading now catches up.
