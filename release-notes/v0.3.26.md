## 中文

### 习题
- 可以自己框出原题区域：在练习页原题图下方，或在题目列表里右键，选「设置原题区域…」，在页面上拖一个框把题目框住，之后「原题」只显示这一块；点「用整页」恢复显示整页。
- 跨页的题：题目接到下一页时（比如图在下一页），在「设置原题区域」上方选好页数，在每一页上各框一块，「原题」会把几块从上到下拼在一起显示。练习页和列表里的页码也写成「第 N–N+1 页」。
- 把题引用到 Agent：练习页顶部或题目列表右键（可以多选）选「在 Agent 中引用」，题目会放进 Agent 的输入框，接着写你要问的就行。
- Agent 能看到你正在练哪一道题、答没答，能帮你打开某道题、某一章、错题本或收藏，也能看原题图。
- `unireader://open?ex=…` 链接会打开那本书的练习页并停在这道题，Agent 给出的题目链接点一下就到。

### Agent
- 你发出的消息下面多了一行「上下文」，列出随这条消息一起发给 Agent、但气泡里看不到的内容：@ 引用、正在看的文档 / 笔记 / 题、引用出处、批改请求、交接摘要。鼠标停在上面可以看原文。
- 打开以前的对话时，你的消息后面不再拼着 @ 附件的文件路径，前后两条消息（比如「继续」）也不再连成一句。
- Agent 可以新建 Markdown 笔记（建在内建笔记文件夹或引用的文件夹里，比如 Obsidian 库），建好后马上出现在侧栏。

### Markdown 笔记
- 可以新建文件夹：在侧栏笔记分组的标题或子文件夹上右键选「新建文件夹…」，或用「文件 › 新建笔记文件夹…」。
- 宽表格用触控板左右滑动时有惯性了，松开手指不再立刻停下。

## English

### Exercises
- You can now box the question yourself: below the Original image on the practice page, or by right-clicking in the question list, choose "Set Question Area…", drag a box around the question, and Original shows only that part of the page. "Use Whole Page" goes back to showing the whole page.
- Questions that span pages: when a question runs onto the next page (say its figure is there), choose the pages at the top of "Set Question Area" and box a part on each page; Original shows the parts one above the other. The practice page and the list show the page as "Pages N–N+1".
- Reference a question in the Agent: on the practice page, or by right-clicking in the question list (several at once if you like), choose "Reference in Agent". The question goes into the Agent's message box, ready for you to type your question.
- The agent can see which question you are practicing and whether you have answered it, can open a question, a chapter, your wrong-answer book or your favorites for you, and can look at the Original image.
- A `unireader://open?ex=…` link opens that book's practice page at the question, so question links given by the agent take you straight there.

### Agent
- Each message you send now has a "Context:" line underneath listing what went to the agent with it but isn't shown in the bubble: @ references, the document, note or question you are viewing, the source of a quote, grading requests and saved contexts. Hover over an item to see the exact text.
- When you reopen an earlier conversation, your messages no longer end with the file paths of @ attachments, and two messages in a row (such as "continue") are no longer run together.
- The agent can create Markdown notes (in the built-in notes folder or a referenced folder such as an Obsidian vault); a new note shows up in the sidebar right away.

### Markdown notes
- You can create folders: right-click a notes group header or a subfolder in the sidebar and choose "New Folder…", or use File › New Notes Folder….
- Scrolling a wide table sideways with the trackpad now keeps its momentum instead of stopping the moment you lift your fingers.
