## 中文

### 新功能和改进
- 设置 › Agent ›「Agent 面板」新增「启动时在后台加载」：打开后，阅读窗口一打开工作区就在后台启动 Agent，切到 Agent 页时已经连好，不用再等。默认关闭；开着时即使从没打开过 Agent 页，Agent 也会一直在运行。
- 给 Agent 的说明里加了写公式的要求：不要把公式放进加粗或斜体里，免得公式显示不出来。

### 修复
- Markdown 笔记里的行内公式含有 `\,`、`\{`、`\|` 这类写法时整条不显示，只露出源码（反斜杠还会消失）。
- `$u(x,y)$`、`$f(x)$` 这类没有运算符的函数写法被当成普通文字，不显示成公式。
- 选中含公式的文字时，公式后面会冒出一个 `$`，压在后一个字上。
- 画板笔记的标签页不在前台时，在平板上滚动，Mac 不记住位置，切回去还停在旧位置。

## English

### New features & improvements
- New option in Settings › Agent › Agent Panel: Load in the background at launch. When on, each reading window starts the agent as soon as it opens a workspace, so the Agent page is ready when you switch to it. Off by default; while it is on, the agent keeps running even if you never open the Agent page.
- The instructions UniReader gives agents now ask them not to put formulas inside bold or italic text when writing notes, so the formulas display properly.

### Fixes
- Inline formulas in Markdown notes that used `\,`, `\{`, `\|` and similar did not display at all; the source showed instead, with the backslash missing.
- Function notation without an operator, such as `$u(x,y)$` or `$f(x)$`, was treated as plain text instead of a formula.
- Selecting text that contains a formula showed a stray `$` after the formula, drawn over the next character.
- Scrolling a board on the tablet while its tab was not in front on the Mac did not save the position; switching back showed the old position.
