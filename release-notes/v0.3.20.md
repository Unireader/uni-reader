## 中文

> 用到服务器的话：**先把服务器升级到 0.3.0，再更新这个版本**。这一版的数据版本是 24，旧服务器会拒收它推上去的改动。

### 新功能：几秒内看到别的设备的改动
- 连接服务器的工作区，开着的时候就能收到其他设备的改动：别处画的笔迹、加的批注、高亮、书签、图片笔记，几秒内就出现在你开着的这本书里，不用关掉再打开。阅读位置不会被拉走。
- 你自己的改动，停手 2 秒后就会传上服务器（以前最久要等一分钟）。

### 新功能：笔记文件也会同步
- 工作区 Notes 里的 Markdown 笔记和附件，现在会在连接服务器的各设备之间同步。在一台电脑上新建或修改，另一台几秒内就能看到。
- 两台设备改了同一篇：不会互相覆盖。先同步的那份留在原处，另一份一字不改，另存成「xxx (冲突 设备名 日期).md」，两份都保留，由你自己处理。
- 别的设备删掉的笔记，这台会放进 Notes 里的隐藏文件夹 .trash，不是直接抹掉。

### 新功能：引用的笔记目录可以在别的设备上只读查看
- 引用了外部笔记目录（比如 Obsidian 的库）的那台电脑，会把它传到服务器。其他没有这个目录的设备，在侧栏里也能看到它，标着「服务器镜像，只读」，可以读、不能改。
- 哪台设备本机有这个目录，就以本机的文件为准。

### 新功能：习题标签
- 习题可以加标签（比如「真题」「2023」）。练习页、列表和顶栏都能按标签筛选；在列表里可以给多道题一起加或去掉标签。终端里的 Agent 通过 MCP 导入或修改习题时也能带标签。

### 新功能：多个 Agent 同时对话
- 一扇窗口里最多可以同时开 6 段 Agent 对话，每段可以选不同的 Agent。Agent 页顶上多了一排标签条，点哪段看哪段，「新建并行对话」开一段新的。

### 改进
- 平板上的习题抽屉，每个分组后面会显示「已做 / 共」多少题。
- Agent 工具调用的标题和输出太长时会截断，避免导入大量习题时界面卡顿。

### 已知限制
- 安卓版暂时还不支持笔记文件同步、引用目录镜像，以及开着时收别的设备的改动。

## English

> If you use a server: **upgrade the server to 0.3.0 first, then update to this version.** This version uses data version 24, and an older server will refuse the changes it pushes.

### New: See changes from your other devices within seconds
- On a workspace connected to a server, changes from your other devices now arrive while the workspace is open: strokes, text notes, highlights, bookmarks and image notes made elsewhere appear in the book you have open within seconds, without closing and reopening it. Your reading position is not moved.
- Your own changes are uploaded 2 seconds after you stop (it used to take up to a minute).

### New: Notes files sync too
- The Markdown notes and attachments in a workspace's Notes folder now sync between the devices connected to the server. Create or edit a note on one computer and the other sees it within seconds.
- If two devices edit the same note, neither overwrites the other. The version that synced first stays in place; the other is saved untouched as "xxx (conflict device date).md", and both are kept for you to sort out.
- A note deleted on another device is moved to a hidden .trash folder inside Notes on this one, not erased.

### New: Read your referenced notes folder on other devices
- A computer that references an outside notes folder (an Obsidian vault, for example) uploads it to the server. Other devices that don't have that folder see it in the sidebar marked "server mirror, read-only": you can read it but not edit it.
- On a device that does have the folder, its own files are always the ones used.

### New: Question tags
- Questions can have tags (such as Past Paper or 2023). Filter by tag on the practice page, in the list and in the toolbar; in the list you can add or remove tags on several questions at once. Agents in the terminal can set tags through MCP when they import or change questions.

### New: Several agents at once
- One window can now hold up to 6 agent chats at the same time, and each chat can use a different agent. The Agent page has a new tab strip: click a tab to see that chat, and New Parallel Chat starts another.

### Improvements
- On the tablet, each group in the exercise drawer now shows how many questions you've done out of the total.
- Very long agent tool-call titles and outputs are now cut off, so importing many questions no longer stalls the window.

### Known limits
- The Android app does not yet support notes file sync, referenced-folder mirrors, or receiving other devices' changes while a workspace is open.
