## 中文

### 笔记里的分步演示（新）
- Markdown 笔记里可以写 ```anim 代码块，画成能一步一步播放的演示：时序图、数组 / 栈 / 队列、链表、树、图、表格、指针，每一步都有说明。
- 一行就能生成常见的演示：停止等待 / 回退 N 帧 / 选择重传、几种排序、CRC 竖式、树的遍历、BFS / DFS、Dijkstra、页面置换、磁盘调度、Cache 映射、进制转换、KMP、散列、堆排序、折半查找、TCP 拥塞控制。
- Agent 可以帮你写这些演示，写错了会指出是哪一行。

### 习题
- 每道题有一张自己的草稿纸：练习页点「草稿纸」，整张纸盖在练习区上，题目卡片浮在上面、可以拖开或收起。平板连着 Mac 时用的是同一张纸，实时同步。原来那块手写小画板去掉了，以前写的内容第一次打开时会搬到纸上。
- 「设置原题区域…」：
  - 页面可以放大（双指捏合或点放大按钮），点一下页面后可以用方向键微调框。
  - 题目跨几页时，每一页都可以选「不显示这一页」，比如只显示下一页上的那一块。
  - 原题图严格按框显示，四周不再多出一圈。

### 搜索
- 「同时按意思搜索」改用下载到本机的模型（Qwen3-Embedding，约 1.2 GB，在设置 › Agent › 搜索里下载），换了说法的内容找得准多了；不联网，内容不离开你的 Mac。
- 模型不用时会自动从内存里卸掉，多久卸可以设置，也可以让它一直留在内存里。
- 设置里可以「查看索引内容…」。

### 其他
- 高亮多了一种画法「删除线」（快捷键 ⌃H）。
- Agent 面板：对话标签上右键可以「重命名对话…」「关闭对话」；思考过程和工具调用那一行，点文字也能展开、收起。
- 「帮助」菜单多了「导出排查日志…」，出问题时可以把日志存成一个文件发给开发者。
- 修正：在表格单元格之间来回点之后，笔记里的公式、表格、演示会消失，页面也滚不动了。

## English

### Step-by-step demos in notes (new)
- Write an ```anim code block in a Markdown note to get a demo you can play one step at a time: sequence diagrams, arrays / stacks / queues, linked lists, trees, graphs, tables and pointers, with an explanation for each step.
- One line is enough for common demos: stop-and-wait / Go-Back-N / Selective Repeat, several sorts, CRC long division, tree traversals, BFS / DFS, Dijkstra, page replacement, disk scheduling, cache mapping, base conversion, KMP, hashing, heap sort, binary search and TCP congestion control.
- The agent can write these demos for you, and it is told which line is wrong if something doesn't parse.

### Exercises
- Every question has its own scratch paper: click Scratch Paper on the practice page and the paper covers the practice area, with the question on a card you can drag aside or fold away. A tablet connected to the Mac uses the same paper, synced live. The small handwriting pad is gone; anything you wrote there moves onto the paper the first time you open it.
- Set Question Area…:
  - Zoom in on the page (pinch or the zoom buttons); after clicking the page, arrow keys nudge the box.
  - For a question that runs over several pages, each page can be set to Don't show this page — for example to show only the part on the next page.
  - Original now shows exactly the box, without the extra margin around it.

### Search
- "Also search by meaning" now uses a model downloaded to your Mac (Qwen3-Embedding, about 1.2 GB, downloaded in Settings › Agent › Search), and finds passages worded differently far more reliably. It works offline and nothing leaves your Mac.
- The model is unloaded from memory when it isn't being used; you can choose after how long, or keep it in memory.
- Settings has Show Indexed Content….

### Also
- A fourth highlight style: Strikethrough (⌃H).
- Agent panel: right-click a chat tab to Rename Chat… or Close Chat; clicking the text of a thinking or tool-call row now expands or collapses it too.
- Help › Export Diagnostic Log… saves the app's recent log to a file you can send to the developer when something goes wrong.
- Fixed: after clicking back and forth between table cells, formulas, tables and demos in the note disappeared and the page stopped scrolling.
