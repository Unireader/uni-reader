## 中文

### 日程（新）
- 侧栏最上面多了「日程」：左边是月历，右边是那一天的待办和每件事的详情。可以加事、打勾、拖到月历上的另一天；过期没做完的和没排日期的单独列出来。每件事的说明支持 Markdown，里面的 `[[…]]` 链接点一下就跳过去。
- Inspector 多了「今天」页：读书时也能看今天要做的事、打勾、加一件；过期没做完的可以「全部挪到今天」。
- 可以请 Agent 排计划：点「请 Agent 安排…」，或直接在 Agent 里说。Agent 会把计划直接写进日程，之后也能按你的进度帮你调整、打勾。
- 日程每个工作区一份，会随离线副本和服务器同步到别的设备。

### Agent
- 工作区记忆：Agent 可以为以后的对话记下简短的事实（比如你的目标、习惯），新对话开头会自动带上。「上下文」菜单里的「管理记忆…」可以查看、修改、删除。
- 对话记录：每一轮问答都存进工作区，Agent 以后能查到以前聊过什么。记忆和对话记录都会同步。
- 搜索：Agent 能一次搜遍工作区里的 PDF 文字、Markdown 笔记、批注和习题，跨行、全角半角、大小写都不影响。设置 › Agent 里可以打开「同时按意思搜索」，换了说法的内容也能找到（默认关）。
- 统计：Agent 能直接数出书、批注、笔记、习题（做了多少、错了多少、按章分）、日程进度这类数字，不用把内容全读一遍。
- Agent 能做的事更多了：给笔记改名、挪目录、删除（进系统废纸篓），查笔记之间的链接和断链，把 PDF 的一页或一块放进笔记当图；修改批注、高亮、书签；改书库里书的显示名和分组；看画板上的手写。
- Agent 的回复和习题的正文改成一段一段显示，拖宽拖窄窗口或面板时不再卡；右键「复制全文（Markdown）」可以复制整条回复。
- 工具调用展开后更好读：行号单独一栏，长输出先显示前 12 行（「显示全部 N 行」），右键「复制输出」。
- 输入框点哪里都能开始打字，不用再找那一小块。

### 知识关联（新）
- 笔记里可以写 `[[书名]]`、`[[书名#page=12]]`，链到书和书的某一页，点了就打开那一页。
- 输入 `[[` 会弹出选择框：笔记、书、正在看的这一页，还能按文字搜书页、批注和笔记段落。批注和图片说明里也能用。
- Inspector 新「关联」页：这一页、这篇笔记链到哪里、被哪里引用，点一下就跳过去。

### Markdown 笔记与表格
- 表格换成圆角样式，笔记、批注和 Agent 回复里都一样。
- 中文表格会按宽度自动折行，不再总要横着滚。
- 拖着选文字经过表格时，整张表按自己的形状高亮，选区不会停在表格中间。
- 单元格的编辑框贴在表格上，不再是一块深色的框；行、列手柄上显示手形，更容易抓到。
- 表格里的行内公式不再偏高。
- 改窗口宽度、拖分栏时，长笔记跟得更快。
- 修正：改名时只改大小写会误报「已存在」；改名会关掉别的窗口里开着的这一篇；改名前没先保存。

### 其他
- 工具栏的「后退」「前进」能跨标签用了：切标签、在标签里换内容、PDF 里跳页都算一步，⌘[ / ⌘] 一样。
- `[[书名#p=12]]` 这种写法的页码也能跳到那一页了。

### 已知问题
- 编辑表格单元格时，整张表偶尔会显示不出来，只剩一片空白；笔记内容不受影响。原因还在查。

### 升级前请看
- 这一版把工作区的数据版本升到 26。用服务器的话，服务器要升到 0.5.0，别的设备上的 UniReader 也要一起升级（安卓 0.3.19 起）。版本不一样时还能从服务器下载，但上传会被拒绝。

## English

### Schedule (new)
- A new Schedule item at the top of the sidebar: a month calendar on the left, the day's to-dos and the details of each one on the right. Add items, check them off, or drag them to another day on the calendar; overdue items and items without a date are listed separately. An item's description supports Markdown, and its `[[…]]` links take you there with one click.
- A new Today page in the Inspector: see what's due today while you read, check things off and add an item; overdue items can be moved over with Move All to Today.
- Ask the agent to make a plan: click Ask Agent to Plan…, or just ask in the Agent panel. The agent writes the plan straight into the schedule, and can later adjust it and check items off as you make progress.
- Each workspace has its own schedule, and it syncs to your other devices through offline copies and servers.

### Agent
- Workspace memory: the agent can note short facts for later conversations (your goals or habits, for example), and new conversations start with them. Manage Memories… in the Contexts menu lets you view, edit and delete them.
- Conversation history: every question and reply is saved in the workspace, so the agent can look up what you talked about before. Memories and conversation history both sync.
- Search: the agent can search a workspace's PDF text, Markdown notes, annotations and exercises in one go, regardless of line breaks, full-width or half-width characters and letter case. Turn on "Also search by meaning" in Settings › Agent to find passages that say the same thing in other words (off by default).
- Statistics: the agent can count books, annotations, notes, exercises (how many done, how many wrong, by chapter) and schedule progress directly, without reading everything.
- The agent can do more: rename notes, move them to other folders and delete them (to the system Trash), check links and broken links between notes, and put a PDF page or part of one into a note as an image; edit annotations, highlights and bookmarks; change a book's display name and group in the library; and look at handwriting on boards.
- Agent replies and exercise text are now shown in separate blocks, so dragging a window or panel wider or narrower no longer stutters. Right-click › Copy All (Markdown) copies a whole reply.
- Expanded tool calls are easier to read: line numbers in their own column, long output shows the first 12 lines (Show All N Lines), and right-click › Copy Output.
- Click anywhere in the message box to start typing; no more hunting for the small active area.

### Links between notes, pages and annotations (new)
- Write `[[book title]]` or `[[book title#page=12]]` in a note to link to a book or one of its pages; clicking it opens that page.
- Typing `[[` opens a picker: notes, books, the page you're on, plus book pages, annotations and note paragraphs found by their text. It works in annotations and image captions too.
- A new Links page in the Inspector shows what this page or note links to and what links to it; click one to go there.

### Markdown notes and tables
- Tables now have a rounded style, the same in notes, annotations and agent replies.
- Tables with Chinese text wrap to the available width instead of always scrolling sideways.
- When you drag a selection across a table, the whole table is highlighted in its own shape, and the selection no longer stops in the middle of it.
- The cell editor sits on the table instead of in a dark box, and the row and column grips show a hand, so they're easier to grab.
- Inline formulas in tables no longer sit too high.
- Long notes keep up better while you resize the window or drag a split.
- Fixed: renaming a note by changing only letter case said the name already existed; renaming closed the note in other windows; the note wasn't saved before renaming.

### Also
- Back and Forward in the toolbar now work across tabs: switching tabs, changing what a tab shows and jumping within a PDF each count as a step. ⌘[ and ⌘] do the same.
- Page links written like `[[book title#p=12]]` also open that page now.

### Known issue
- While you edit a table cell, the whole table occasionally isn't shown and only blank space is left; the note's content is not affected. We're still looking into the cause.

### Before you upgrade
- This version moves workspace data to version 26. If you use a server, upgrade it to 0.5.0 and update UniReader on your other devices too (Android 0.3.19 or later). With different versions you can still download from the server, but uploads are refused.
