## 中文

本版汇总 0.1.39 以来的改动。

### 扫描页对齐
- 「视图」菜单新增「对齐扫描页」：扫描件里文字歪斜、每页正文位置不一样时打开它。第一次打开会先检测全书（页数多时要等几秒，阅读区顶部显示进度），之后每页文字都会转正，翻页时正文不再左右跳动，页与页之间的字号也保持一致。
- 按文件记住，默认关闭。检测结果会保存下来，关掉再打开不用重新检测。
- 切换前会弹窗提示：这篇文档已有的笔迹、高亮、笔记和书签不会跟着页面移动，位置可能对不上；已识别的文字（OCR）结果会清除，需要重新识别。建议在还没开始做批注的扫描书上使用。
- 打开对齐后再识别文字，识别出的文字位置与页面更贴合，选字和高亮更准。
- 连接平板时，平板上看到的也是对齐后的页面；参考小窗、缩略图、框选截图同样按对齐后的页面显示。
- 离线副本同步时会一并带上这个设置。

### 已知问题
- 只校正文字的角度和左右位置，上下位置没有校正（连续滚动阅读时看不出差别）。
- 暂时没有「重新检测」的入口。

## English

This release covers changes since 0.1.39.

### Align Scanned Pages
- The View menu adds "Align Scanned Pages": turn it on for scanned books whose text is tilted or sits in a different place on every page. The first time, UniReader analyzes the whole document (a few seconds for long books, with progress shown at the top of the reading area). After that every page is straightened, the text column no longer jumps left and right as you turn pages, and text size stays consistent from page to page.
- The setting is remembered per file and is off by default. The analysis is saved, so turning it off and on again doesn't redo it.
- Before switching, a dialog warns that existing ink, highlights, notes and bookmarks in this document will not move with the pages and may end up out of place, and that text recognition (OCR) results will be cleared and need to be recognized again. It's best used on scanned books you haven't annotated yet.
- Text recognized after alignment is turned on lines up more closely with the page, so text selection and highlights are more accurate.
- A connected tablet shows the aligned pages too, as do the reference window, thumbnails and area snapshots.
- Offline copies carry this setting when you sync.

### Known Issues
- Only the tilt and horizontal position are corrected; vertical position is not (the difference isn't noticeable when scrolling continuously).
- There is no "re-analyze" option yet.
