## 中文

### 新功能
- 习题可以写笔记：做完一道题后，在解析下面点「添加笔记」，可以给错题记下易错点、思路，支持 Markdown 和 `$…$` 公式。笔记边写边自动保存，点「完成」或按 Esc 收起；写到一半翻到别的题或切换标签页也不会丢。笔记在作答之后才显示，重做时不会先看到。习题列表里多了一列「笔记」。
- 习题顶栏新增「重做上次做错的」：只留下最近一次做错的题，全部重新作答，从第一道开始。答对的下次就不再出现，可以一轮一轮把错题做到全对。它和「只看没做过」只能开一个；在错题本里也能用，正好挑出还没做对的题。
- 可以让 Agent 帮你写或修改某道题的笔记，Agent 也能读到你写的笔记。Agent 重新导入题目时不会覆盖你的笔记。

## English

### New
- Exercises can now have notes: after answering a question, click "Add a Note" below the explanation to write down common mistakes or the approach, with Markdown and `$…$` formulas. Notes save automatically as you type; click Done or press Esc to close the editor, and nothing is lost if you switch to another question or tab halfway. Notes only appear after you answer, so they don't give the answer away when you redo a question. The exercise list has a new My Note column.
- A new "Redo Last Wrong" button in the exercise toolbar keeps only the questions you got wrong last time, ready to answer again from the first one. Questions you get right drop out next time, so you can work through your mistakes round by round. It can't be on together with "Not Done Only", and it also works in Mistakes, where it picks out the questions you haven't got right yet.
- You can ask the Agent to write or edit a question's note, and the Agent can read your notes. Re-importing exercises with the Agent doesn't overwrite your notes.
