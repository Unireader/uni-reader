## 中文

### 新功能和改进
- Agent 面板里你发出的话也按 Markdown 显示：粗体、列表、行内代码、公式、表格等和 Agent 的回复一样排版；短句的气泡按文字长短收窄。
- Agent 回复里的代码块按语言着色（代码块开头写了语言名才着色，例如 swift、python），浅色和深色外观各有一套配色，代码块也有了底色。`==文字==` 显示为荧光笔高亮。
- 在 Agent 面板里右键表格，可以「复制表格」：贴进笔记是 Markdown 原文，贴进 Numbers、Excel、Pages 是一张表格。右键代码块，可以「复制代码」，只复制代码本身。
- Agent 能分清两种笔记：文字笔记（右键「在此添加批注」或选中文字后添加、钉在页面上的那种）和 Markdown 笔记。你只说「笔记」时，正在看 PDF 就按文字笔记理解，正在看 Markdown 笔记就按 Markdown 笔记理解。通过 MCP 连接的外部 Agent 同样适用。

### 修复
- 在 Agent 面板里右键表格时，不再出现盖住半张表的错位蓝色选中框。
- 选中代码块时，不再露出代码块首尾的围栏标记和语言名。

## English

### New features & improvements
- In the Agent panel, what you send is now shown as Markdown too: bold, lists, inline code, math, tables and so on are laid out just like the agent's replies, and short messages get a bubble that fits the text.
- Code blocks in agent replies are colored by language (when the code block names its language, such as swift or python), with separate colors for light and dark appearance, and code blocks now have a background. `==text==` shows as a highlighter mark.
- Right-click a table in the Agent panel and choose Copy Table: it pastes as Markdown into notes and as a real table into Numbers, Excel or Pages. Right-click a code block and choose Copy Code to copy just the code.
- Agents now tell the two kinds of notes apart: text notes (the ones pinned on a page, added with right-click ▸ Add Note Here or by selecting text) and Markdown notes. When you just say "note", an agent takes it as a text note if you are looking at a PDF, and as a Markdown note if you are looking at a Markdown note. This also applies to external agents connected over MCP.

### Fixes
- Right-clicking a table in the Agent panel no longer shows a misplaced blue selection covering half the table.
- Selecting a code block no longer reveals the code fence markers and language name.
