## 中文

### Markdown 笔记
- 表格单元格里的链接显示成链接：`[文字](链接)` 显示文字，`[[笔记名]]` 显示笔记名，书页链接显示成 `p.12`；找不到的 `[[…]]` 显示为灰色。原先这些都按源码原样显示。
- 点表格里的链接文字就能打开，和正文里的链接一样；点格子的其他地方仍是编辑这一格，按住 Option 点链接也是编辑。
- 表格里的书页链接（`p.12`）把鼠标停在上面会显示书名和页码。
- Agent 面板的回复和习题正文里，表格中的链接也能点了。

### 网页
- 网页会记住页内滚动到的位置：重新打开、切回这个标签或重新载入后都会回到原来的位置，连续刷新时页面不再一点点往上跑。

## English

### Markdown notes
- Links in table cells now show as links: `[text](url)` shows its text, `[[note]]` shows the note name, and links to a book page show as `p.12`. A `[[…]]` that can't be found is shown in gray. All of these used to show as source.
- Click a link's text in a table to open it, as in body text. Clicking elsewhere in the cell still edits it, and so does Option-clicking a link.
- Hover over a book page link (`p.12`) in a table to see the book's name and the page.
- Links in tables can now be clicked in Agent replies and exercise text too.

### Web pages
- Web pages remember how far you scrolled: reopening a page, switching back to its tab or reloading it returns to the same place, and reloading several times in a row no longer makes the page creep upward.
