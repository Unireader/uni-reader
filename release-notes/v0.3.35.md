## 中文

### 网页（静态 HTML 课件）
- 可以把一个网页文件夹（HTML、图片、样式、脚本、视频）导入工作区：「文件 › 导入网页文件夹…」，或在侧栏「网页」一段上右键。也可以只选其中一个 HTML 文件，它就是首页。
- 网页在标签页里打开，顶上有后退、前进、重新载入；也可以点「在浏览器中打开」，用默认浏览器查看（只在这台 Mac 上能访问）。
- 侧栏右键可以重命名、换首页、从文件夹重新导入新版本、删除（删除的可以在「文件 › 回收站…」里找回）。
- 课件里的脚本可以用 `window.unireader` 保存学习进度、做题记录等数据，这些数据存在工作区里，在浏览器里打开时读写的也是同一份。
- 网页和保存的数据会随离线副本、服务器同步到其他设备。经服务器同步课件文件需要服务器 0.8.0 或更新。

### Agent
- Agent 可以列出网页、读和修改其中的文件、新写一份课件或导入一个文件夹、打开给你看、读写课件保存的数据，以及删除网页。

## English

### Web pages (static HTML lessons)
- Import a web page folder (HTML, images, styles, scripts, videos) into the workspace with File ▸ Import Web Page Folder…, or by right-clicking the Web Pages section in the sidebar. You can also pick a single HTML file in the folder; it becomes the start page.
- Web pages open in a tab with Back, Forward and Reload at the top. Open in Browser shows the page in your default browser (reachable from this Mac only).
- Right-click in the sidebar to rename, change the start page, re-import a newer version from a folder, or delete (deleted pages can be put back from File ▸ Recently Deleted…).
- Scripts in a lesson can use `window.unireader` to save progress, answers and other data in the workspace; the page reads and writes the same data when opened in the browser.
- Web pages and their saved data sync to your other devices through offline copies and the server. Syncing lesson files through a server needs server 0.8.0 or later.

### Agent
- Agents can list web pages, read and change their files, write a new lesson or import a folder, show one to you, read and write the data a lesson saved, and delete web pages.
