## 中文

### 新功能：Agent 上下文，换一个 Agent 接着聊
- Agent 页标题行多了「上下文」按钮。点「保存这段对话为上下文」，当前的 Agent 会把这段对话写成一份摘要，存进工作区。
- 换一个 Agent（比如从 Kimi 换成 Claude Code）开新对话，在「上下文」菜单里点那一份，它会随你的下一句话一起发过去，新的 Agent 就知道之前做到哪了。
- 「管理上下文…」里可以查看、修改标题和摘要；删除的会先放进回收站，可以放回。
- 终端里的 Agent 通过 MCP 也能列出、读取、保存这些上下文。
- 连接服务器的工作区里，上下文会同步到其他设备，需要服务器 0.2.2 或更新版本。

### 新功能：答对自动下一题
- 练习页底部多了「答对自动下一题」。勾上后，答对了停一下就自动翻到下一题；答错会停在这一题，方便看解析。这台 Mac 会记住你的选择。

## English

### New: Agent contexts — carry on with a different agent
- The Agent page header has a new Contexts button. Choose Save This Chat as a Context, and the current agent writes a summary of the chat, which is saved in the workspace.
- Start a new chat with another agent (say, Claude Code instead of Kimi), pick that context from the Contexts menu, and it goes along with your next message, so the new agent knows where you left off.
- Manage Contexts… lets you view and edit the title and summary. Deleted contexts go to Recently Deleted, where you can put them back.
- Agents in the terminal can also list, read and save contexts through MCP.
- In workspaces on a server, contexts sync to your other devices. This needs server 0.2.2 or later.

### New: Next When Right
- The practice page has a new Next When Right checkbox at the bottom. When it's on, getting a question right takes you to the next one after a moment; get it wrong and you stay on that question to read the explanation. Your Mac remembers the setting.
