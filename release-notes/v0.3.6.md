## 中文

### 请注意
- **用安卓平板连接 Mac 的话，平板请同时更新到安卓版 0.3.9 或更新**。旧版平板收不到新写的笔迹，草稿纸和画板上刚写的字会显示不出来。下载：https://github.com/Unireader/uni-reader-android/releases/tag/2026-10-10-1

### 新功能和改进
- Agent 面板打开很长的对话时更快：先只显示最近的一段，往上翻时再接着显示更早的内容，翻动时眼前的内容不会跳。
- Markdown 笔记里能显示更多公式写法：`\big` 一类的括号大小、`\dfrac`、`\tfrac`、`\cfrac`、`\dots`、`\leqslant`、`\lvert`、`\operatorname`、`\iint`、`\pmod`、`\not=`、`\implies`、`\boldsymbol`、`\mathscr`、`\varnothing`、`\tag`；`$y'$` 这类带撇号的写法和 `$0$` 这类纯数字也显示成公式。
- 平板在画板和草稿纸上写字时，Mac 每写完一笔只把新写的那几笔发给平板，分页画板也只发平板所在页附近的几页，不再每次把整块画板重发一遍。
- 一次显示大量公式时，内存占用大幅下降。
- 给 Agent 的说明里补充了目前还显示不了的公式写法（如 `\boxed`、`\overset`、`cases`），分段函数改用 `aligned` 来写。

### 修复
- 用平板在分页画板上使用橡皮擦时，Mac 卡住、一直转彩虹圈。
- 画板页数多、笔迹多时，平板写几笔就卡住，刚写的笔迹显示不出来。
- 一句中文里出现两个 `$` 时，中间的中文被误当成公式。
- 加粗紧挨着中文、全角括号或中文标点时不生效，`**` 原样显示出来。
- 公式里空白命令紧挨着加减号时（如 `x = \; -1`），间距不对。

## English

### Please note
- **If you use an Android tablet with your Mac, update the tablet to UniReader for Android 0.3.9 or later at the same time.** Older tablet versions miss the new strokes, so what you just wrote on a scratch pad or board does not show up on the tablet. Download: https://github.com/Unireader/uni-reader-android/releases/tag/2026-10-10-1

### New features & improvements
- Long conversations open faster in the Agent panel: only the most recent part is shown at first, and earlier messages load as you scroll up, without the content in view jumping.
- Markdown notes can display more formula notation: `\big` and related bracket sizes, `\dfrac`, `\tfrac`, `\cfrac`, `\dots`, `\leqslant`, `\lvert`, `\operatorname`, `\iint`, `\pmod`, `\not=`, `\implies`, `\boldsymbol`, `\mathscr`, `\varnothing`, `\tag`. Primes such as `$y'$` and plain numbers such as `$0$` now display as formulas too.
- When writing on a board or scratch pad from the tablet, the Mac now sends only the new strokes after each stroke, and for paged boards only the pages near where the tablet is, instead of resending the whole board every time.
- Much lower memory use when many formulas are displayed at once.
- The instructions UniReader gives agents now list the formula notation that cannot be displayed yet (such as `\boxed`, `\overset` and `cases`), and ask for piecewise functions to be written with `aligned`.

### Fixes
- Using the eraser on a paged board from the tablet made the Mac hang with the spinning wait cursor.
- On a board with many pages and a lot of ink, the tablet froze after a few strokes and the new strokes did not appear.
- When a Chinese sentence contained two `$` signs, the text between them was mistaken for a formula.
- Bold did not work when it was right next to Chinese text, full-width brackets or Chinese punctuation; the `**` showed as-is.
- Wrong spacing in formulas where a spacing command sat right next to a plus or minus sign (such as `x = \; -1`).
