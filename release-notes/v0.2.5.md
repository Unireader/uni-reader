## 中文

### 修复
- Markdown 笔记里输入的英文单引号 `'` 和双引号 `"` 不会再被自动换成中文弯引号 `’` `”`，公式（如 `$f'(x)$`）里也一样。
- 笔记小窗比较窄时，笔记内容会按窗口宽度折行，不会再有超出窗口、看不到的部分。
- Agent 请求权限时，请求说明和选项按钮不会再挤在同一行、叠在一起；面板较窄时，按钮会改为上下排列。

## English

### Fixes
- Straight quotes `'` and `"` typed in Markdown notes are no longer turned into curly quotes `’` `”`, including inside formulas such as `$f'(x)$`.
- In a narrow note window, note text now wraps to the window width instead of running off the edge.
- When the Agent asks for permission, the request and the option buttons no longer pile up on one line; in a narrow panel the buttons stack vertically.
