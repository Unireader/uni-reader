## 中文

### 标签改用系统标签页
- 标签不再是阅读区底部的胶囊，改成 macOS 系统的窗口标签，显示在工具栏下面（和 Safari、访达一样）。
- 可以拖动排序、把标签拖出来变成单独的窗口再拖回去，也可以用「窗口 › 显示所有标签页」总览；⌃Tab / ⌃⇧Tab 切换，⌘W 关闭当前标签。
- 切换标签时，侧栏和检查器保持不动：开合、宽度、检查器当前页、侧栏的展开和滚动位置都跟着上一个标签。
- 同一个工作区的所有标签共用一组 Agent 对话；在哪个标签里提问，就带上哪个标签的文档和页码。
- 工具栏「返回」/ ⌘[ ⌘] 可以跨标签回到上一处。
- ⌘N、⌘T 和标签栏的「+」都会新开一个标签并弹出快速打开，可以模糊搜索要打开的内容。
- 退出后重新打开，标签会按原来的顺序回来、停在上次的那个；没切到过的标签用到时才加载，启动更快。

### 标题统一显示在工具栏
- Markdown 笔记：笔记名显示在工具栏标题，路径显示在标题下方，笔记顶部不再重复显示名字。改名用菜单「文件 › 重命名笔记…」，或在侧栏右键「重命名…」。
- 网页：工具栏标题显示网页自己的标题，下方显示网页在书库里的名字。网页铺满到工具栏后面，顶部那一条去掉了；后退、前进改用工具栏的「返回」和 ⌘[ ⌘]；首页、重新载入、在浏览器中打开放进一个可以拖动的小工具条。

### 快速打开（⌘P）
- 支持多段模糊匹配和拼音搜索，还能直接搜到单道习题和目录项。

### 画板与草稿纸
- 页数多的画板打开更快：页面先显示出来，笔迹随后补上；在大画板里滚动、缩放也更流畅。
- 无限画布右下角小地图里的视口框现在会跟着移动。

### 侧栏
- 打开文档、网页后，它们在侧栏里的位置不再变动（新加的排在前面，手动排过的顺序照旧）。

### 阅读区
- 文字笔记的图钉和卡片滚到工具栏下面时，会和页面一样从工具栏后面透出来，不再被切掉一截。

### 连接服务器的工作区
- 打开工作区时不再先等同步，窗口马上出现，同步在后台进行。
- 新增设置「退出前与服务器同步」（设置 › 服务器），默认关闭，退出更快；没来得及推送的改动会在下次打开这个工作区时同步。

## English

### Tabs are now system tabs
- Tabs are no longer a capsule at the bottom of the reading area. They are now standard macOS window tabs, shown under the toolbar (like Safari and Finder).
- Drag to reorder, drag a tab out into its own window and back, or use Window › Show All Tabs. Switch with ⌃Tab / ⌃⇧Tab; ⌘W closes the current tab.
- The sidebar and inspector stay put when you switch tabs: open or closed, width, the inspector's current page, and the sidebar's expanded folders and scroll position all carry over.
- All tabs of a workspace share one set of agent conversations; a question carries the document and page of the tab you ask it from.
- The toolbar's Back button and ⌘[ ⌘] can return to a place in another tab.
- ⌘N, ⌘T and the tab bar's + button open a new tab with Quick Open, so you can fuzzy-search what to open.
- After quitting and reopening, tabs come back in the same order with the last one selected. Tabs you haven't switched to load when you first open them, so launching is faster.

### Titles shown in the toolbar
- Markdown notes: the note's name is the toolbar title and its path is shown below it; the note no longer repeats its name at the top. Rename with File › Rename Note… or right-click › Rename… in the sidebar.
- Web pages: the toolbar title is the page's own title, with the web page's name in the library below it. The page now fills the area behind the toolbar and the bar at its top is gone. Back and forward use the toolbar's Back button and ⌘[ ⌘]; Home, Reload and Open in Browser are in a small floating toolbar you can drag.

### Quick Open (⌘P)
- Matches several fragments and pinyin, and can find individual questions and contents entries directly.

### Boards and scratchpads
- Boards with many pages open faster: the pages appear first and the strokes follow. Scrolling and zooming in large boards are smoother.
- On infinite boards, the viewport frame in the minimap now follows as you move around.

### Sidebar
- Documents and web pages no longer move in the sidebar after you open them (new ones go first; your manual order stays).

### Reading area
- Text note pins and cards now show through the toolbar like the page does when scrolled under it, instead of being cut off.

### Server workspaces
- Opening a workspace no longer waits for a sync first: the window appears right away and syncing continues in the background.
- New setting Sync with the server before quitting (Settings › Server), off by default, so quitting is faster. Changes not yet sent are synced the next time you open the workspace.
