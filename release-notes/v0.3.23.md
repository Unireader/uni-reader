## 中文

### Markdown 笔记
- 输入 `[[` 时会弹出工作区里的笔记，接着打字可以筛选；用 ↑ ↓ 选、回车确认，就写成 `[[笔记名]]`。按 Esc 收起。
- 支持 `==高亮==`：两个等号夹着的文字显示为高亮。整页笔记、批注编辑框和页面上的笔记气泡都认。

### Agent
- 在输入框开头打 `/`，会列出当前 Agent 提供的命令，选中后补全成 `/命令名`，接着写参数。
- 在 PDF 上选中一段文字，右键可以把它作为引用放进 Agent 输入框，再接着写你的问题。Agent 会知道这段话出自哪本书第几页。

### 批注
- 选中文字加的批注，图钉现在可以拖到别处，高亮的位置不变。右键图钉选「图钉放回原位」可以恢复。

### 连接服务器
- 一次同步要从服务器删除的东西很多时（比如删了一本批注很多的书），会先暂停，在工作区菜单里点「确认删除…」确认后才上传。
- 两台设备改了同一处时仍然自动处理，现在可以在工作区菜单的「同步冲突…」里看到处理了哪些。
- 退出 App 时会先把改动传上服务器再退出（最多等 4 秒）。
- 开着画板或练习页时，别的设备上的改动会在几秒内显示出来，不用关掉重开。
- 开着一本 PDF 时，如果它在别的程序里被改了内容（比如加了目录），切回来会提示「文件已变化」，可以关联为新版本。
- 从服务器打开一个工作区后，第一次同步不再把里面的图片重新上传一遍。

## English

### Markdown notes
- Typing `[[` now lists the notes in your workspace; keep typing to filter. Use ↑ ↓ to choose and Return to confirm, and it becomes `[[Note Name]]`. Press Esc to dismiss.
- `==highlight==` is supported: text between two pairs of equals signs is shown highlighted. It works in full-page notes, the annotation editor and note bubbles on the page.

### Agent
- Type `/` at the start of the input to list the commands the current agent offers. Picking one completes it to `/command` so you can go on with its arguments.
- Select text in a PDF and right-click to quote it in the Agent input, then add your question. The agent is told which book and page the quote comes from.

### Annotations
- For an annotation made on selected text, you can now drag its pin somewhere else; the highlight stays where it is. Right-click the pin and choose Put Pin Back to restore it.

### Servers
- When a sync would delete a lot from the server (for example after deleting a book with many annotations), it pauses first. Choose Review Deletions… in the workspace menu to confirm before anything is uploaded.
- Changes made to the same item on two devices are still resolved automatically; you can now see what was resolved under Sync Conflicts… in the workspace menu.
- Quitting the app uploads your changes to the server first (waiting up to 4 seconds).
- While a board or a practice page is open, changes from your other devices show up within seconds, without closing and reopening it.
- If a PDF you have open is changed in another program (for example, a table of contents is added), switching back shows File Changed so you can link it as a new version.
- After opening a workspace from a server, the first sync no longer uploads its images again.
