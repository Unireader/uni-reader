## 中文

### 新功能和改进
- 新增「画板笔记」：工作区里一篇独立文档，不挂在任何 PDF 上，在标签页里打开就是一张随手书写、画图、贴图片的板子。侧栏「画板笔记」右键或 ⌃⌘N 新建，支持笔、橡皮、尺子、框选、缩放、剪贴板、撤销、纸样背景和小地图，也可以拖入、粘贴或插入图片，图片可以移动缩放、双击看大图。
- 新建时可以选「无限画布」或「分页」。分页画板整本统一页面大小（A4 / A5 / Letter / 当前屏幕，可横版），背景模板有空白 / 横线 / 方格 / 点阵 / 康奈尔 / 两栏，可以单独设某一页，也可以所有页一起设；写到底部继续上拉自动加新一页，页面列表里还能插页、删页。
- 平板同步支持画板笔记：用平板在浏览器打开工作区，可以直接在画板上书写，也能新建画板和分页画板、改每页背景。
- 删除画板笔记会先进回收站，保留期内可以恢复。

## English

### New features & improvements
- New Board notes: a standalone document in your workspace that doesn't belong to any PDF. Open one in a tab and it's a board for free writing, drawing, and pasting images. Create it from the sidebar (right-click) or ⌃⌘N; it comes with pens, eraser, ruler, lasso select, zoom, clipboard, undo, paper backgrounds and a minimap. Images can be dropped, pasted or inserted, then moved, resized, and viewed full-size.
- When creating a board, choose an infinite canvas or paged. A paged board keeps one page size for the whole book (A4 / A5 / Letter / current screen, portrait or landscape) and offers blank / lined / square grid / dots / Cornell / two-column backgrounds, per page or for all pages at once. Pull past the bottom to add a page; the page list lets you insert and delete pages.
- Boards work on the tablet too: open the workspace in the tablet browser to write on a board, create infinite or paged boards, and change page backgrounds.
- Deleted boards go to the trash first and can be restored within the retention period.
