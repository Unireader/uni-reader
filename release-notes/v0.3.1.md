## 中文

### 新功能和改进
- 新增「书写锁定」：打开后只能在当前这支笔和橡皮之间切换，不会误切到别的笔。可以在笔架上的锁形开关、菜单或快捷键 ⌥⌘L 开关，平板上的开关与 Mac 同步。
- 新增「相对粗细」模式：开启后，落笔时按当前缩放折算笔的粗细——放大后写字，缩回原尺寸看，粗细和放大前一致。笔架上和笔的编辑面板里都能开关，平板与 Mac 同步。
- 画板会记住上次看到的位置和缩放，重新打开时回到离开时的地方，而不是画布原点。

## English

### New features & improvements
- New Writing Lock: while it's on, you can only switch between the current pen and the eraser, so you won't pick another pen by accident. Toggle it from the lock switch on the pen rack, the menu, or ⌥⌘L; the setting stays in sync with the tablet.
- New Relative ink width: when on, pen thickness is scaled to the current zoom as you write — write zoomed in, and it looks the same once you zoom back out. Toggle it on the pen rack or in the pen editor; the setting stays in sync with the tablet.
- Boards remember where you left off: reopening a board returns to the last position and zoom instead of the canvas origin.
