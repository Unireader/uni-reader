## 中文

### Markdown 笔记
- 指向书中某一页的链接（`[[书名#page=152]]`）现在只显示页码，比如「p.152」，鼠标停在上面能看到书名和页码。文件里写的内容不变，光标移进链接时照样显示原文。

### 修正
- 列表和引用里较高的公式（比如分式）不再压到上下两行。
- 表格单元格里的公式含有竖线时（比如 $|A|$），不再被当成分隔符拆成两格。
- 竖线前带系数的公式（比如 $k|A|$、$2|x|$）能正确显示，不再显示成原文。
- Agent 在表格里写公式时，改用不会和表格冲突的写法。

## English

### Markdown notes
- Links to a page in a book (`[[Book title#page=152]]`) now show just the page number, such as "p.152"; hover over one to see the book title and page. What's written in the file doesn't change, and the original text still shows when the cursor moves into the link.

### Fixes
- Tall formulas (such as fractions) in lists and quotes no longer overlap the lines above and below.
- A formula with vertical bars inside a table cell (such as $|A|$) is no longer split into two cells.
- Formulas with a coefficient before the bars (such as $k|A|$ and $2|x|$) now display correctly instead of showing their source.
- When the Agent writes formulas in tables, it now uses a form that doesn't conflict with the table.
