# UniReader 习题识别导入

App 只负责存题和练习；**看图、转写、对答案都是你的事**。固定的导入格式就是 MCP 工具 `import_exercises` 的输入，
方案见仓库里的 `EXERCISE-PLAN.md`。本轮只支持**单选 / 多选**。

## 前提

- UniReader 正在运行，MCP 服务已开（设置 › Agent），**写入开关已打开**（导入、补答案都是写入）。
- 已配置好 MCP 连接（例：`claude mcp add --transport http unireader http://127.0.0.1:8773/mcp`）。
  在 App 自带的 Agent 面板里用时不用配。
- 只经 MCP 读写。**绝不直接打开 `library.sqlite`**（App 之外再开一份库会丢数据，项目红线）。

## 流程

1. `get_state` → 当前工作区、key 窗口开着哪篇。用户说了书名就 `list_documents` 按 `title` 找 `document_id`；
   没说就用 key 窗口那篇。用户没说页码就问，**别整本扫**。
2. 先 `list_exercises`（带 `document_id`、`pages`）看这几页是不是已经导过：导过的题再导一次会**更新**而不是重复，
   但能少做一遍就少做一遍。
3. 逐页看：`render_page`（`width` 给 1440，题目小字多时给 2160）看图，`read_pages` 拿同一页的文字对照。
   - 文字以**图上看到的为准**；`read_pages` 的 OCR 文本只用来抄准公式以外的字、核对数字。
   - 跨页的题（题干在上一页底、选项在下一页顶）记在**题干开始的那一页**。
4. 每页按阅读顺序整理成题，调 `import_exercises`（一次 ≤50 道；一页一调或几页一调都行）：

   ```json
   {
     "document_id": "…",
     "exercises": [
       {
         "page": 23,
         "number": "5",
         "section": "习题 2.3",
         "type": "single",
         "stem": "设 $f(x)=x^2$，则 $f'(1)=$",
         "options": [{"key": "A", "text": "$0$"}, {"key": "B", "text": "$1$"},
                     {"key": "C", "text": "$2$"}, {"key": "D", "text": "$4$"}],
         "answer": "C",
         "answer_source": "book",
         "explanation": "……",
         "region": [0.08, 0.31, 0.84, 0.12],
         "has_figure": false
       }
     ]
   }
   ```

   - **用户已经做过的题**（用户 2026-10-11：选择题一般**高亮**作答，部分手写）：同一页先
     `list_annotations`（`kinds: ["highlight"]`、`pages`）拿高亮，每条有 `quote`（高亮到的原文）和 `rects`（位置）。
     高亮落在哪道题的选项上（位置在题目框里、原文对得上某个选项）就是选了哪个；再 `render_page` 带 `include_marks: true`
     看手写（圈了字母、旁边写了答案）。认出来的填进 `user_answer`（`"B"` / `"AC"`）。
     **认不准的不填**——同一道题高亮了两个选项、或者手写看不清，就别猜，在汇报里列出来让用户自己看。
     题干里被高亮的关键词不是作答，别当成选项。
5. 看返回：`rejected` 的题会带 `reason`，按原因改了**只重发那几道**。
6. 答案在书后（答案页 / 答案册）的：翻到答案页同样 `render_page` 看，`list_exercises` 按 `number` + `section`
   对上 id，`update_exercises` 补 `answer` + `answer_source: "book"`（+ `explanation`）。
   补上答案后，App 会把这道题之前「没法判」的作答（包括 `user_answer`）重新判一遍，判错的自动进错题本。
7. 完成后告诉用户：导了哪几页、新增几道 / 更新几道、几道没答案、几道标了带图、认出了几道书上的作答
   （几道错）；退回又改不好的、作答认不准的列出来。

## 字段怎么填

| 字段 | 规则 |
|---|---|
| `page` | 1 起，题干所在页 |
| `number` | **书上印的题号原样**（`"5"`、`"例 3"`、`"(2)"`）。强烈建议填：同页同章节同题号 = 同一道题，重导只更新 |
| `section` | 题号会在不同小节重复时一定要填（「习题 2.3」「2023 年真题」），按书上印的写 |
| `type` | `single` / `multiple`。题目写了「多选」「不定项」或答案不止一个 → `multiple` |
| `stem` | 题干**逐字转写**，不改写、不补充、不删「（　）」这类括号；公式规则见下 |
| `options` | 按印刷顺序，`key` 用书上的字母，`text` 不带「A.」前缀 |
| `answer` | 选项字母，`"B"` / `"AC"`。**不知道就不填**，以后补 |
| `answer_source` | 填了 `answer` 就必须填：书上印的 → `book`；你自己解的 → `agent`（App 会提示用户「未经核对」） |
| `explanation` | 书上有解析就照抄；没有可以写自己的思路（但答案来源仍要如实标） |
| `region` | 整道题（题干 + 选项）在页上的框 `[x, y, w, h]`，0~1、左上原点，与 `render_page` 的图同一坐标。宁可稍大不要切掉字。练习时用户点「原题」看的就是这一块 |
| `has_figure` | 题目或选项依赖图 / 表 / 函数图像、文字说不全 → `true`。练习时默认把原题截图摆出来；选项本身是图时 `text` 可以留空 |
| `chapter` | **一般不填**：App 按题目所在页码去 PDF 自带的目录里找（最深一级的完整路径），用户在侧栏按「课本 + 章节」练。只有自动找的会错时才填——比如习题集中在书后、PDF 没有目录——这时用 `get_document` 看目录，按目录里的原名从顶层写到要挂的那一级（`["第二章 导数", "2.3 求导法则"]`） |
| `user_answer` | 用户在书上已经做过的作答（高亮的选项 / 手写的字母），见流程第 4 步。没做过的不填；认不准的不填 |

公式：`$…$` 行内、必须在一行里；`$$…$$` 独占几行做块公式；**不要**用 `\(…\)`、`\[…\]`。
渲染器画不了 `\boxed`、`cases` / `align` 等环境，分段函数用 `\left\{\begin{aligned} … \end{aligned}\right.`。
公式别放在 `**粗体**` 里。

## 不要做的事

- 不要改写题目（「精简一下题干」「把选项排个序」都不行）——用户是要照着书练。
- 看不清的字不要猜：整题标 `has_figure: true`，并在汇报里说出哪几道看不清。
- 不要把自己解出来的答案标成 `book`。
- 不要把**自己解的答案**填进 `user_answer`——那一栏只放用户在书上留下的作答。
- 不要导入非选择题（填空 / 解答 / 判断）：本轮工具不收，跳过并在汇报里说一句有几道。
- 不要为了「整理」去删用户的题：`delete_exercises` 只在用户明确要求时用（删了进回收站，可恢复）。
