# UniReader 习题识别导入与批改

App 只负责存题和练习；**看图、转写、对答案、批改都是你的事**。固定的导入格式就是 MCP 工具 `import_exercises` 的输入，
方案见仓库里的 `EXERCISE-PLAN.md`（填空 / 主观题在 §11）。支持四种题型：**单选 / 多选 / 填空（`fill`）/ 主观题（`subjective`）**。
判断题还不支持（跳过并在汇报里说一句有几道）。

## 前提

- UniReader 正在运行，MCP 服务已开（设置 › Agent），**写入开关已打开**（导入、补答案都是写入）。
- 已配置好 MCP 连接（例：`claude mcp add --transport http unireader http://127.0.0.1:8773/mcp`）。
  在 App 自带的 Agent 面板里用时不用配。
- 只经 MCP 读写。**绝不直接打开 `library.sqlite`**（App 之外再开一份库会丢数据，项目红线）。

## 流程

1. `get_state` → 当前工作区、key 窗口开着哪篇。用户说了书名就 `list_documents` 按 `title` 找 `document_id`；
   没说就用 key 窗口那篇。用户没说页码就问，**别整本扫**。
2. 先 `list_exercises`（带 `document_id`、`pages`）看这几页是不是已经导过：导过的题再导一次会**更新**而不是重复，
   但能少做一遍就少做一遍。
3. 逐页看：`render_page`（`width` 给 1440，题目小字多时给 2160）看图，`read_pages` 拿同一页的文字对照。
   - 文字以**图上看到的为准**；`read_pages` 的 OCR 文本只用来抄准公式以外的字、核对数字。
   - 跨页的题（题干在上一页底、选项在下一页顶）记在**题干开始的那一页**。
4. 每页按阅读顺序整理成题，调 `import_exercises`（一次 ≤50 道；一页一调或几页一调都行）：

   ```json
   {
     "document_id": "…",
     "exercises": [
       {
         "page": 23,
         "number": "5",
         "section": "习题 2.3",
         "type": "single",
         "stem": "设 $f(x)=x^2$，则 $f'(1)=$",
         "options": [{"key": "A", "text": "$0$"}, {"key": "B", "text": "$1$"},
                     {"key": "C", "text": "$2$"}, {"key": "D", "text": "$4$"}],
         "answer": "C",
         "answer_source": "book",
         "explanation": "……",
         "region": [0.08, 0.31, 0.84, 0.12],
         "has_figure": false
       },
       {
         "page": 24, "number": "8", "section": "习题 2.3", "type": "fill",
         "stem": "设 $f(x)=x^3$，则 $f'(1)=$ ______，$f''(1)=$ ______。",
         "blanks": [{"answer": "3"}, {"answer": "6"}],
         "answer_source": "book",
         "region": [0.08, 0.52, 0.84, 0.06]
       },
       {
         "page": 24, "number": "12", "section": "习题 2.3", "type": "subjective",
         "stem": "证明：$\\sqrt{2}$ 是无理数。",
         "answer": "反证法。设 $\\sqrt{2}=\\frac{p}{q}$，$p,q$ 互质……",
         "answer_source": "book",
         "region": [0.08, 0.60, 0.84, 0.10]
       }
     ]
   }
   ```

   - **填空题**：题干照印刷保留空（`______` / `（　）`），`blanks` 按阅读顺序**一空一项**；参考答案写在 `blanks[].answer`
     （公式照样用 `$…$`），书上给了几种等价写法、或你确定某种写法也算对的，放进 `accept`（如 `$\\frac{1}{2}$` 的 `accept: ["0.5"]`）。
     答案**要么每空都给、要么都不给**（不知道就 `[{}, {}]`，以后 `update_exercises` 补）。App 拿用户写的和这些逐空比对
     （忽略空格、全角半角），全对得上直接判对，对不上的交给用户自己判或请你批改。
   - **主观题**（计算、证明、简答、论述）：没有 `options`，参考答案 / 解答过程写在 `answer`（Markdown + 公式），
     书上只有最终结果就只写结果；练习时用户对照它自己判对错，或者请你批改。
   - 一道大题带几个小问：每个小问能独立作答就拆成几道（`number` 写 `"3(1)"`、`"3(2)"`），否则整道作为一道主观题。

   - **用户已经做过的题**（用户 2026-10-11：选择题一般**高亮**作答，部分手写）：同一页先
     `list_annotations`（`kinds: ["highlight"]`、`pages`）拿高亮，每条有 `quote`（高亮到的原文）和 `rects`（位置）。
     高亮落在哪道题的选项上（位置在题目框里、原文对得上某个选项）就是选了哪个；再 `render_page` 带 `include_marks: true`
     看手写（圈了字母、旁边写了答案）。认出来的填进 `user_answer`（`"B"` / `"AC"`）。
     **认不准的不填**——同一道题高亮了两个选项、或者手写看不清，就别猜，在汇报里列出来让用户自己看。
     题干里被高亮的关键词不是作答，别当成选项。
     填空题书上写的填进 `user_blanks`（一空一格，空着的写 `""`），主观题书上写的转写进 `user_answer`；
     这两种存进去是「还没判」，导完可以接着按下面「批改作答」判掉。
5. 看返回：`rejected` 的题会带 `reason`，按原因改了**只重发那几道**。
6. 答案在书后（答案页 / 答案册）的：翻到答案页同样 `render_page` 看，`list_exercises` 按 `number` + `section`
   对上 id，`update_exercises` 补 `answer` + `answer_source: "book"`（+ `explanation`）。
   补上答案后，App 会把这道题之前「没法判」的作答（包括 `user_answer`）重新判一遍，判错的自动进错题本。
7. 完成后告诉用户：导了哪几页、新增几道 / 更新几道、几道没答案、几道标了带图、认出了几道书上的作答
   （几道错）；退回又改不好的、作答认不准的列出来。

## 字段怎么填

| 字段 | 规则 |
|---|---|
| `page` | 1 起，题干所在页 |
| `number` | **书上印的题号原样**（`"5"`、`"例 3"`、`"(2)"`）。强烈建议填：同页同章节同题号 = 同一道题，重导只更新 |
| `section` | 题号会在不同小节重复时一定要填（「习题 2.3」「2023 年真题」），按书上印的写 |
| `type` | `single` / `multiple` / `fill` / `subjective`。题目写了「多选」「不定项」或答案不止一个 → `multiple`；有横线 / 括号要填 → `fill`；计算、证明、简答、论述 → `subjective` |
| `stem` | 题干**逐字转写**，不改写、不补充、不删「（　）」「______」这类空；公式规则见下 |
| `options` | 只有选择题有：按印刷顺序，`key` 用书上的字母，`text` 不带「A.」前缀 |
| `blanks` | 只有填空题有：一空一项 `{"answer": "…", "accept": ["…"]}`，按阅读顺序；答案要么全给要么全不给 |
| `answer` | 选择题：选项字母，`"B"` / `"AC"`；主观题：参考答案 / 解答（Markdown + 公式）；填空题不用（写在 `blanks`）。**不知道就不填**，以后补 |
| `answer_source` | 填了 `answer` 就必须填：书上印的 → `book`；你自己解的 → `agent`（App 会提示用户「未经核对」） |
| `explanation` | 书上有解析就照抄；没有可以写自己的思路（但答案来源仍要如实标） |
| `region` | 整道题（题干 + 选项）在页上的框 `[x, y, w, h]`，0~1、左上原点，与 `render_page` 的图同一坐标。宁可稍大不要切掉字。练习时用户点「原题」看的就是这一块 |
| `has_figure` | 题目或选项依赖图 / 表 / 函数图像、文字说不全 → `true`。练习时默认把原题截图摆出来；选项本身是图时 `text` 可以留空 |
| `chapter` | **一般不填**：App 按题目所在页码去 PDF 自带的目录里找（最深一级的完整路径），用户在侧栏按「课本 + 章节」练。只有自动找的会错时才填——比如习题集中在书后、PDF 没有目录——这时用 `get_document` 看目录，按目录里的原名从顶层写到要挂的那一级（`["第二章 导数", "2.3 求导法则"]`） |
| `user_answer` | 用户在书上已经做过的作答：选择题是高亮的选项 / 手写的字母，主观题是转写的文字，见流程第 4 步。没做过的不填；认不准的不填 |
| `user_blanks` | 填空题用户在书上写的，一空一格（空着的写 `""`）。没做过的不填；认不准的不填 |

公式：`$…$` 行内、必须在一行里；`$$…$$` 独占几行做块公式；**不要**用 `\(…\)`、`\[…\]`。
渲染器画不了 `\boxed`、`cases` / `align` 等环境，分段函数用 `\left\{\begin{aligned} … \end{aligned}\right.`。
公式别放在 `**粗体**` 里。

## 不要做的事

- 不要改写题目（「精简一下题干」「把选项排个序」都不行）——用户是要照着书练。
- 看不清的字不要猜：整题标 `has_figure: true`，并在汇报里说出哪几道看不清。
- 不要把自己解出来的答案标成 `book`。
- 不要把**自己解的答案**填进 `user_answer`——那一栏只放用户在书上留下的作答。
- 不要导入判断题：工具还不收，跳过并在汇报里说一句有几道。
- 不要为了「整理」去删用户的题：`delete_exercises` 只在用户明确要求时用（删了进回收站，可恢复）。
- 批改时不要把自己的判定标成用户自己判的，也不要去改题目的参考答案来迁就用户的作答。

## 批改作答（填空 / 主观题）

用户在 App 里做的填空 / 主观题，程序判不了的会记成「还没判」。用户在练习页点「让 Agent 批改」时，输入框里那句话后面
带着题目和作答的 id（隐藏说明里），手写部分附成了图片；用户也可能直接说「批改今天做的主观题」。

1. 找作答：给了 id 就 `list_exercise_attempts`（`exercise_ids: ["…"]`）；没给就 `list_exercise_attempts`（`ungraded_only: true`，
   需要时带 `document_id`）。每条有题干、`reference_answer`、用户写的 `answer` / `blanks`（填空还有 `blank_matches`：每空和参考答案一字不差没有）。
2. `has_handwriting: true` 的用 `render_exercise_answer` 看手写（用户可能只写在画板上，`answer` 是空的）。
3. 对照参考答案判：
   - 填空：`blank_matches` 为假的空看是不是等价写法（`0.5` 与 $\frac{1}{2}$、`x>1` 与 $(1,+\infty)$），等价就算对。
   - 主观题：看结论和关键步骤；结论对但关键步骤缺失、或过程有实质错误的，判错并指出来。
   - 没有参考答案的：自己解一遍再判，评语里说明「没有参考答案，按我的解答判」。
4. `grade_exercise_attempts`：`correct` + `feedback`（**用用户的语言**，几句话：哪里对、哪里错或缺、怎么改；公式规则同上）。
   你的判定会覆盖用户自己判的，判错的题进错题本。一次 ≤50 条。
5. 汇报：批了几道、几道对几道错，最需要注意的一两点。
